# Разделы приложения для брифа QA

Порядок разделов в брифе — как здесь. `id` — для `brief.json` и `changes.sh`.

«Пути» — **единственный источник** раскладки коммитов: `scripts/changes.sh` читает эту строку (одна строка,
только пути в обратных кавычках через запятую — без пояснений). Файл относится к первому разделу сверху вниз,
чей путь — сам файл или его папка; поэтому узкие пути (`composeApp/…/FastMountWiring.kt`) стоят выше широких
(`composeApp` в `platform`). `*` — любая часть пути (`core/localization/*/fastmount.xml` — строки раздела на
всех языках). Один и тот же путь в нескольких разделах (модуль `feature/device/autostart` — у `bypass` и
`clone`) — файл попадает во все эти разделы. Что раздел ещё затрагивает — в «Связано».

«Источники» — что читать, чтобы описать раздел. Строки экранов — только в `core/localization`:
`core/localization/src/commonMain/composeResources/values-ru/<префикс>.xml` (префикс модуля — в «Источниках»,
ключи `<префикс>_<экран>_…`, `docs/localization.md`). Своих `strings.xml` в фичах нет.

Платформы: **Android** (телефон), **iOS** (iPhone), **Desktop** (macOS / Windows). Bluetooth — только телефон
(на desktop его нет); USB — Android (OTG) и desktop.

## auth — Авторизация

- Пути: `feature/login`, `feature/auth-state`, `core/localization/*/login.xml`, `core/localization/*/authstate.xml`
- Источники: `feature/login/AGENTS.md`, `feature/auth-state/AGENTS.md`, строки `login.xml`, `authstate.xml`.
- Всегда проверять: вход; неверный логин/пароль; регистрация; восстановление пароля; активация аккаунта;
  выход и повторный вход; перезапуск приложения — сессия сохраняется; нет интернета при старте — экран
  ошибки проверки и «Повторить». Порядок: ошибки полей регистрации и занятый email — до регистрации, вход в
  неактивированный аккаунт — сразу после регистрации, ошибка восстановления пароля — до восстановления.
  Переключателя языка на экране входа нет (язык — только в «Настройках»). Клавиатура закрывается тапом мимо
  поля — проверять на iOS отдельным шагом.
- Платформы: все.

## home — Главный экран

- Пути: `feature/main`, `feature/app-settings`, `feature/account`, `core/localization/*/main.xml`, `core/localization/*/appsettings.xml`, `core/localization/*/app.xml`
- Источники: `feature/main/AGENTS.md`, `feature/app-settings/AGENTS.md`, `feature/account/AGENTS.md` (профиль в
  боковом меню), строки `main.xml`, `appsettings.xml`, `app.xml`, `design/features/home`.
- Всегда проверять: плитки и куда ведёт каждая (Быстрый монтаж, Расширенный монтаж, Конфигуратор настроек,
  Архив прошивок, Автомобили, Чат тех. поддержки и др. — неготовые плитки: что происходит при нажатии);
  боковое меню (профиль, версия, выход; на низком экране меню прокручивается; профиль — из кэша без сети,
  обновляется при открытии меню и кнопкой у профиля); «Обновить базу» без интернета — ошибка; «Настройки» —
  язык приложения (сохраняется, применяется после ручного перезапуска приложения на всех платформах) и язык конфигураций
  (сразу: каталог и облачные конфигурации в конфигураторе и быстром монтаже — на выбранном языке); баннер обновления приложения; синхронизация базы устройств;
  поворот / размер окна (телефон, планшет, широкое окно desktop). Плитка «Чат тех. поддержки» видна, пока
  сервер не ответил «чат недоступен»; часов работы у поддержки нет — кейс «в рабочее время» не заводить.
  «Проверить обновления» в меню — только desktop. «Автомобили» сначала спрашивает тип устройства.
  Профиль может быть без email («Email не указан») — это не баг.
- Платформы: все.

## appearance — Оформление

- Пути: `feature/appearance`, `core/ui/src/commonMain/kotlin/ru/alarmtrade/specmp/core/ui/theme`, `core/files`, `core/localization/*/appearance.xml`
- Источники: `feature/appearance/AGENTS.md`, `core/ui/AGENTS.md` (тема), `docs/ui-kit.md` («Система тем»), строки
  `appearance.xml`; макет `design/features/appearance/`.
- Всегда проверять: вход из бокового меню → «Оформление»; готовые темы (Pandora — как приложение без настроек,
  Графит, Контраст, Мастерская, Ночная смена) в светлой и тёмной; цвета отдельно для светлой и тёмной, редактор
  цвета: неверный HEX, цвет с плохим контрастом — «Готово» недоступно, «Подобрать» ставит подходящий; фон — свечение /
  заливка / градиент (направления); размер текста 100–150 % (с крупным системным шрифтом приложение не растёт
  больше ×1,5); скругления общим ползунком и по элементам; заливка кнопок (контурная недоступна при слабом
  акценте), форма, отступы кнопок и чипов; «Одинаково для обеих тем» вкл/выкл; предпросмотр меняется, само
  приложение — только после «Применить»; «Отменить» возвращает применённую; «Применить» перекрашивает всё
  приложение сразу, без перезапуска; тема сохраняется после перезапуска; переключение светлая/тёмная в меню
  после своей темы; экспорт `.json` (отмена — без сообщения) и импорт: свой файл, чужой файл («не файл темы»),
  файл с плохими цветами (снекбар «исправлено N»); поворот / широкое окно (настройки слева, предпросмотр справа).
  Пипетки нет — это не баг. Приложение прошивки (`flasherApp`) темы не получает.
- Платформы: все (импорт/экспорт — системный выбор файла на каждой платформе).

## fast-mount — Быстрый монтаж

- Пути: `feature/fast-mount`, `composeApp/src/commonMain/kotlin/ru/alarmtrade/specmp/navigation/FastMountWiring.kt`, `core/localization/*/fastmount.xml`
- Связано: шаги мастера из `bypass` и `clone` и `check-state` (проверка системы), выбор конфигурации
  из `configurator`, поиск из `scan` (только сигнализации) — их изменения могут менять и быстрый монтаж.
- Источники: `feature/fast-mount/AGENTS.md`, строки `fastmount.xml`, `design/features/fast-mount`.
- Всегда проверять: поиск — не сигнализации пунктиром и недоступны; блок не из базы / микробот → «Блок не
  поддерживает»; проверка блока (готов / новая прошивка — рекомендация / заводской CAN и нет доступа — «Далее»
  недоступна); автомобиль → конфигурация («Выбрать», несовпадение CAN) → сводка с планом (USB — без Slave и
  проверки); «Готовим монтаж» и ошибка сервера; запись настроек (замок) и ошибка; монтаж — карта PDF (скачивание,
  открытие, ошибка), фото на весь экран, «Монтаж завершён?»; перезагрузка с таймером, 60 с → потеря связи; обход и
  Clone в мастере («Далее» на итоге, «Вернуться к монтажу?»); Slave («Обучение выполнено»); проверка системы —
  задания по порядку, «Завершить» с незакрытыми; отзыв обязателен; «Готово» → главная; другой блок после
  переподключения; «Назад» на каждом шаге; колонка шагов на планшете и desktop (справка по тапу); озвучка «Руки
  заняты» — кнопка в шапке на шагах обхода, Clone и проверки системы (на остальных шагах её нет), включённая
  озвучка запоминается для следующих монтажей; на проверке системы звучат текущее задание, «— есть сигнал» у
  автозаданий, «— не пройдено» / «— пропущено» и «Проверка завершена: пройдено N из M»; выход из мастера —
  голос замолкает.
- Платформы: Android, iOS (Bluetooth); Android, Desktop (USB — без Slave и проверки системы).

## advanced-mount — Расширенный монтаж

- Пути: `feature/advanced-mount`, `core/localization/*/advancedmount.xml`
- Источники: `feature/advanced-mount` (экраны `presentation/screen`), строки `advancedmount.xml`,
  `feature/device/AGENTS.md` (режимы блока).
- Всегда проверять: шапка блока (модель, ID, режим «Рабочий / Загрузчик», Bluetooth / USB, версии ПО,
  CAN-код, IMEI); «Читаем возможности блока…» и ошибка проверки на сервере; разделы и их доступность
  (заблокированные — «Сначала обновите CAN-прошивку»); блок, которого нет в базе устройств; выход и
  повторный вход в монтаж.
- Платформы: Android, iOS (Bluetooth), Android/Desktop (USB).

## passport — Паспорт монтажа

- Пути: `feature/mount-passport`, `composeApp/src/commonMain/kotlin/ru/alarmtrade/specmp/navigation/MountPassportWiring.kt`, `composeApp/src/commonMain/kotlin/ru/alarmtrade/specmp/mountpassport`, `composeApp/src/commonMain/kotlin/ru/alarmtrade/specmp/fastmount`, `composeApp/src/commonMain/kotlin/ru/alarmtrade/specmp/assistant/AppAssistantPassportRepository.kt`, `core/localization/*/mountpassport.xml`
- Связано: входы — блок «Паспорт монтажа» на финале `fast-mount`, плитка `advanced-mount`, плитка «Паспорта
  монтажа» на `home`, плитка и последний шаг ассистента (раздел `advanced-mount`); считывание блока зависит от
  `connection`.
- Источники: `feature/mount-passport/AGENTS.md`, `feature/fast-mount/AGENTS.md` («Паспорт на финале»), строки
  `mountpassport.xml`, `fastmount.xml` (`fastmount_done_*passport*`), `mountassistant.xml`
  (`mountassistant_passport_*`), `design/features/mount-passport`.
- Всегда проверять: входы — финал быстрого монтажа («Оформить паспорт» → считывание → предотчёт → «Паспорт
  готов» внутри мастера, «Назад» → финал, затем «Паспорт оформлен · №» + «Поделиться» / «Открыть»; «На главную»
  без паспорта — в архиве заготовка «Дооформить»), плитка расширенного монтажа (сигнализация и модуль, BT и USB →
  паспорта блока, «Новый паспорт»), плитка главного экрана (архив, поиск, «Новый паспорт без блока»), ассистент
  (плитка после «Состояния», поиск «паспорт / акт / документ / отчёт / pdf», последний «Следующий шаг» и
  карточка «Монтаж закончен? Оформите паспорт» → после оформления «Паспорт оформлен · №» + «Открыть»);
  считывание по этапам и остановки (обрыв связи, другой блок, пропуск настроек); предотчёт — поля, валидация
  VIN/пробега/телефона, фото (лимит 8), «Перечитать»; «Паспорт готов» — листы PDF, «Поделиться», «Сохранить
  файл», «Открыть», «Изменить»; дооформление заготовки; паспорт без блока; удаление.
- Перенос архивом (ZIP): экспорт одного паспорта («⋯» строки → «Экспорт (ZIP)», «⋯» «Паспорт готов» → «Экспорт
  паспорта (ZIP)»), выбранных (архив: «⋯» / «Экспорт» → режим выбора, «Выбрать все», заготовку отметить нельзя,
  «Экспорт: N») и всех («Экспорт всех»); переключатели «Снимок настроек блока» (нет снимков — замок) и «Фото в
  полном качестве» (по умолчанию выкл.) — состав архива на другом устройстве; «Собираем архив… Паспорт i из N» →
  «Поделиться» / «Сохранить файл» (отмена сохранения — «Архив готов», повтор без пересборки); телефон — лист
  снизу, планшет/desktop — диалог. Импорт: «Импорт из файла» → «Выбрать файл» (отмена — ничего), не ZIP / чужой ZIP
  → «Это не архив паспортов», архив из новой версии → «Нечего импортировать» / «Не импортированы», сводка «Новый /
  Уже есть», «Пропустить» (по умолчанию) / «Заменить», итог «Импортировано / Заменено / Пропущено», паспорта сразу в
  архиве, фото и снимок настроек открываются; большой архив (100+ паспортов, фото 2048) — без зависаний и вылетов.
  Напоминание «Сохраните копию архива» (раз в месяц): «Позже» скрывает, «Экспорт всех» после сборки — убирает.
- Платформы: Android, iOS (Bluetooth); Android, Desktop (USB, архив); на desktop нет «Поделиться».

## bypass — Бесключевой обход (автозапуск)

- Пути: `feature/device/autostart`, `core/localization/*/autostart.xml`
- Связано: шаг «Обход иммобилайзера» в `fast-mount`; итог «нужен Clone» ведёт в `clone`; вход в режим
  программирования (PIN) — общий с `check-state`.
- Источники: `feature/device/AGENTS.md` (раздел «Бесключевой обход и Clone»), строки `autostart.xml`
  (`autostart_bypass_*`, `autostart_common_*`, `autostart_pin_*`), `design/features/bypass-clone`,
  `.claude/tasks/autostart-bypass-clone.md`.
- Всегда проверять: расширенный монтаж → «Бесключевой обход»; PIN программирования (неверный PIN, пауза после
  ошибки); обучение по шагам до итога (успех, ошибка с подсказкой «что проверить», итог «нужен Clone» →
  «Перейти к процедуре Clone» и «Назад» в обход с сохранённым итогом); инструкции для отдельных марок;
  критичные ожидания «Не прерывайте соединение»; обрыв связи во время обучения → «Процедура прервана»;
  выход во время процесса — подтверждение; чат техподдержки с экрана ошибки; озвучка «Руки заняты» — кнопка в
  шапке (выкл / вкл / говорит — пульсирует / нет голоса — красная точка и «Нет голоса»: на телефоне лист, на
  планшете и desktop — диалог, Android — «Установить голос»), первое включение — подсказка один раз (закрывается
  «Понятно» или сама через 7 с), включение на шаге — сразу звучит текущий шаг; звучат «Начинаем обучение обхода»,
  каждый новый шаг (текст карточки), «Обход обучен» / ошибка, обрыв связи; выключение, уход с экрана и сворачивание
  приложения — голос замолкает; PIN и выход не озвучиваются; Linux — кнопки нет.
- Платформы: Android, iOS (Bluetooth); Android, Desktop (USB). Только на тестовом блоке и машине.

## clone — Процедура Clone

- Пути: `feature/device/autostart`, `core/localization/*/autostart.xml`
- Связано: тот же модуль, что `bypass` (изменения попадают в оба раздела); шаг «Clone» в `fast-mount`.
- Источники: `feature/device/AGENTS.md` (раздел «Бесключевой обход и Clone»), строки `autostart.xml`
  (`autostart_clone_*`, `autostart_common_*`, `autostart_pin_*`), `design/features/bypass-clone`,
  `.claude/tasks/autostart-bypass-clone.md`.
- Всегда проверять: вход из расширенного монтажа («Процедура Clone») и из итога обхода («Вернуться к обходу»);
  число попыток и подтверждение запуска; этапы «нажимать ничего не нужно»; на этапах записи выйти нельзя
  (замок вместо «Назад», системный «Назад» не срабатывает); неверный PIN внутри процедуры; обрыв связи —
  «Попытка не потрачена» до вычисления на сервере, позже «Проверьте число попыток» и перечитанный счётчик;
  «уже выполнено»; «Повторить» (только при оставшихся попытках); чат техподдержки с экрана ошибки; озвучка «Руки
  заняты» (кнопка как в `bypass`) — «Этап N из 5: …», на этапах записи — «Не прерывайте соединение» (кнопка
  озвучки работает и при замке), итог, обрыв.
- Платформы: Android, iOS (Bluetooth); Android, Desktop (USB). Только на тестовом блоке и машине — попытки
  Clone ограничены.

## check-state — Проверка состояния блока

- Пути: `feature/device/state`, `core/localization/*/devicestate.xml`
- Связано: шаг «Проверка системы» в `fast-mount` (задания по порядку).
- Источники: `feature/device/AGENTS.md` (раздел «Проверка состояния»), строки `devicestate.xml`,
  `design/features/check-state`.
- Всегда проверять: плитка есть только при подключении по Bluetooth; состояние обновляется само (раз в
  несколько секунд), «Нет данных N с» при долгом молчании блока; «Подробно» — зоны, двигатель, связь,
  дополнительно; команды — по одной, удержание кнопки (запуск двигателя и паника — подтверждение с удержанием),
  итог на кнопке и «Повторить»; режим программирования с PIN; уйти с экрана и вернуться — опрос продолжается;
  потеря связи и переподключение; широкая раскладка на планшете; озвучка «Руки заняты» — кнопка в шапке (и в низком
  окне телефона-ландшафта рядом со статусом), изменения зон звучат как на экране («Капот: Открыт»), несколько
  изменений за пару секунд — одной фразой, открыли и сразу закрыли — тишина; в быстром монтаже экран молчит
  (говорит чек-лист мастера).
- Платформы: Android, iOS (только Bluetooth).

## scan — Поиск и выбор устройства

- Пути: `feature/device/selection`, `core/localization/*/deviceselect.xml`
- Источники: `feature/device/AGENTS.md` (раздел про selection), строки `deviceselect.xml`.
- Всегда проверять: поиск по Bluetooth, по USB и одновременно (разные тексты подсказок); нет разрешений
  (Android: «Устройства поблизости», iOS: Bluetooth) → «Открыть настройки»; Bluetooth выключен; на старых
  Android выключена геолокация; пустой список и советы; несколько блоков в списке; карточка устройства
  (MAC, тип) и «Подключить».
- Платформы: Android, iOS (Bluetooth); Android, Desktop (USB).

## connection — Подключение и потеря связи

- Пути: `feature/device/interaction`, `feature/device/interaction-ui`, `core/localization/*/deviceinteraction.xml`
- Источники: `feature/device/AGENTS.md` (сессия, переподключение, тайминги), строки `deviceinteraction.xml`.

  подключении → сразу экран обновления прошивки.
- Платформы: Android, iOS (Bluetooth); Android, Desktop (USB).

## firmware — Прошивки

- Пути: `feature/device/firmware`, `core/localization/*/firmware.xml`
- Источники: `feature/device/AGENTS.md` (раздел «Прошивка»), строки `firmware.xml`.
- Всегда проверять — **все типы**: основная прошивка блока, CAN-модуль, Bluetooth-модуль; источники версии —
  последняя с сервера, архив (более старая — подтверждение отката), файл с диска; PIN программирования
  (только Bluetooth: неверный PIN, пауза 15 с после ошибки); вход в загрузчик и возврат в рабочий режим;
  обрыв связи во время передачи (продолжение / ошибка); «Выйти из режима обновления?»; архив прошивок с
  главного экрана и из карточки автомобиля (только просмотр); CAN-фильтр архива (4 цифры, выбор автомобиля).
- Платформы: Android, iOS (Bluetooth); Android, Desktop (USB). Прошивка — на тестовом блоке, не на машине клиента.

## settings — Расширенные настройки блока

- Пути: `feature/device/settings`, `feature/device/settings-ui`, `core/localization/*/settings.xml`
- Источники: `feature/device/AGENTS.md` (раздел «Расширенные настройки», «Конфигурации в редакторе»),
  строки `settings.xml`, `design/features/device-settings`.
- Всегда проверять: чтение настроек из блока; дерево разделов, поиск; изменение значений всех видов
  (переключатель, список, число, время, CAN-код с выбором автомобиля); счётчик «Изменено» и «Записать»;
  выход с незаписанными изменениями; сброс к заводским; потеря связи во время чтения и записи; меню «⋯» —
  «Загрузить из…» (файл, заводские, мои, облако) с окном «Что изменится», «Сохранить в…» (мои, файл).
- Платформы: все (desktop — только USB).

## configurator — Конфигуратор настроек

- Пути: `feature/configurator`, `feature/configurator-ui`, `core/localization/*/configurator.xml`
- Источники: `feature/configurator/AGENTS.md`, строки `configurator.xml`, `design/features/configurator`,
  `.claude/tasks/configurator.md` (раздел «Статус» — что сознательно не сделано).
- Всегда проверять: «Мои конфигурации» — поиск, фильтр модели, создание (с нуля / из облака / из файла),
  копия, переименование, удаление; выбор модели блока (недавние и их удаление); редактор конфигурации —
  только просмотр, «Сохранить», «Сохранить как…», выход с несохранёнными; облако — выбор автомобиля, список
  («Лучшие / Новые»), карточка, «Сохранить в мои»; «Записать в блок» — из раздела «Конфигуратор настроек» в
  расширенном монтаже (с главного экрана записи в блок нет); облако после смены языка конфигураций в настройках; сохранение и открытие файла `.dxs` на каждой платформе.
  Порядок: «нет интернета при выборе модели» и «недавние модели» — до создания конфигурации. Список моделей
  приходит с сервера (без сети — «Нет подключения к интернету»), а создание и сохранение «Моих» работает без
  сети — это не баг. Модель без настроек в базе — редактор пишет «Для этой модели нет настроек». Широкое окно:
  ширину списка можно перетащить, она запоминается. Облако: сортировка «Лучшие / Новые» — переключатель над
  списком конфигураций автомобиля (Конфигуратор настроек → «Создать» → «Из облака» → автомобиль).
- Платформы: все.

## vehicle — Автомобили

- Пути: `feature/vehicle`, `feature/vehicle-ui`, `core/localization/*/vehicle.xml`
- Источники: `feature/vehicle/AGENTS.md`, строки `vehicle.xml`, `design/features/vehicle-select`.
- Всегда проверять: каталог марок → моделей → комплектаций; поиск по названию и по CAN-коду (4 ячейки);
  недавние (и удаление); фильтр; карточка автомобиля — вкладки (функции, схемы, карты монтажа), прокрутка
  под вкладками, архив прошивок из карточки; выбор автомобиля из настроек (CAN-код) и из архива прошивок;
  раскладки телефон / планшет / широкое окно; полоса прокрутки в списках; ширина колонок на широком окне
  перетаскивается и запоминается. Значки «Блокировка по CAN» и «Бесключевой обход» — два отдельных, значения
  («поддерживается / не поддерживается / нет данных») и вкладки карточки приходят с сервера: вкладка видна,
  только если для неё есть данные; фильтр функций может скрыть вкладку «Функции». Кейс на конкретный значок
  или вкладку — только с автомобилем (CAN-код), который дал разработчик, иначе «найти любой автомобиль, где …».
- Платформы: все.

## support-chat — Чат техподдержки

- Пути: `feature/support-chat`, `core/localization/*/supportchat.xml`
- Источники: `feature/support-chat/AGENTS.md`, строки `supportchat.xml`.
- Всегда проверять: история и подгрузка старых сообщений; отправка текста, картинки, документа; нет сети —
  плашка и очередь; повтор / удаление неотправленного; открытие и скачивание вложений; большой файл.
  Часов работы нет: специалист отвечает, когда подключится. Обрыв связи, повтор/удаление неотправленного и
  скачивание вложений — в preconditions «стабильная сеть, есть возможность её выключить (офис)». Большой файл —
  в preconditions указать размер лимита и где взять файл. «Повторить» на весь экран — только если чат открыт
  без сети; пропала сеть при открытом чате — плашка «нет соединения», переподключение само.
- Платформы: все.

## tech-requests — Заявки на техпомощь

- Пути: `feature/tech-requests`, `core/localization/*/techrequests.xml`
- Источники: `feature/tech-requests/AGENTS.md`, строки `techrequests.xml`; макет `design/features/tech-requests/`.
- Всегда проверять: вход с главного экрана (без блока: список, отмена/закрытие, «Новая заявка» → «Подключить
  блок») и из расширенного монтажа (с блоком); секции «Активные / Завершённые», подгрузка старых; форма — маска
  телефона (Россия, другая страна, вставка «8 (900)…»), ошибки полей после первой попытки, счётчик с 1700 и
  лимит 2000; отправка по этапам «Читаем настройки блока… → Отправляем заявку…», «Отмена» во время отправки,
  успех с номером и подсветкой новой; «Вопрос решён» / «Отменить заявку» с подтверждением; обрыв связи с блоком
  во время отправки. Реальные заявки уходят в живую поддержку — в preconditions: тестовый аккаунт, описание
  «тест», заявку закрыть после проверки. Лимит незакрытых заявок вживую не воспроизводить.
- Платформы: все (создание — с подключённым блоком: телефон по Bluetooth, Android/desktop по USB).

## platform — Общее и платформы

## Не для QA

`design/`, `docs/`, `.ai/`, `.claude/`, `.agents/`, `.codex/`, `.gemini/`, любые `*.md`, а также файлы вне путей
разделов (например, `flasherApp`) — в бриф не попадают: `changes.sh` выводит их в «Прочее» (`other`) только для
сведения. Новый модуль приложения в «Прочем» — повод добавить его путь в подходящий раздел здесь.
