# flasherApp

- Область: composition root мини-приложения прошивки (ветка `feature/flasher-app`). Обёртки — `flasherAndroidApp`, `flasherDesktopApp`. Только Android и desktop: COM-порта на iOS в SDK нет — сборка на `specmp.kmp.android-jvm` + `specmp.kmp.compose` (без `iosArm64`).
- Пакет `ru.alarmtrade.specmp.flasher`. `FlasherApp(appVersionName, appVersionCode)` — тот же старт, что у `App()` (`composeApp`): язык, `AppStartViewModel` (`SpecialistInitializer` как `AppStartup` и `AppServicesStarter`), `BindEffect` разрешений (слоты — `di/FlasherServicesModule.kt`: `DeviceSession.start()`); Koin-модули — только авторизация (`authStateModule`, `loginModule`) и устройство/прошивка (`deviceSelectionModule`, `deviceInteractionModule`, `deviceInteractionUiModule`, `deviceFirmwareModule`).
- Список Koin-модулей — `di/FlasherKoinModules.kt` (`flasherKoinModules(…)`), полноту графа проверяет `jvmTest` `FlasherKoinModulesTest` (koin-test `verify`).
- Навигация (`navigation/FlasherNavigation.kt`): `AuthStateNavGraph` → логин (первая версия; финальная — без авторизации: убрать `AuthStateNavGraph`/`LoginNavGraph` и модули `auth-state`/`login`, корнем станет поиск) → `ScanRoute` (поиск — корень, без «Назад», с COM-портами) → `DeviceRoute(serial)` (заменяет поиск в стеке, выход — снова новый `ScanRoute`: VM поиска не переживает сессию; `serial` — транспорт из `onSessionCreate(transport)`, своей VM нет) — `DeviceInteractionHost` для любого транспорта; контент выбирается по `serial`: BLE/USB — `FirmwareFileScreen`, загрузчик — `FirmwareBootGraph(sources = FileOnly)`; COM — `SerialFirmwareScreen` в обоих слотах. Описание экранов — `feature/device/AGENTS.md`, «COM-порт и приложение прошивки».
- Пикер файла прошивки — общий `rememberFirmwareFilePicker(appScope, ioDispatcher)` из `feature:device:firmware` (как в `composeApp`; app-scope и диспетчер корень достаёт `koinInject`, фичи — нет: Konsist `composable-injection`); `di/PlatformKoinModules` повторяет реализацию `composeApp`: корни приложений друг от друга не зависят, общий код корней выносится в `core/*`/фичи (CPD, `docs/code-quality.md`).
- Строки — в `core/localization` (`firmware_*`, `deviceselect_*`), своего префикса у модуля нет.
- Запуск — общая `AppStartViewModel` (`core/ui`, регистрация — `di/FlasherServicesModule.kt`).
