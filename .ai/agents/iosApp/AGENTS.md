# iosApp

- Область: Swift bootstrap, iOS project settings и интеграция общего framework в `iosApp`.
- Перед изменениями читай `docs/build.md`.
- Общую UI- и бизнес-логику ищи в KMP-модулях, а не в `iosApp`.
- Экран не гаснет, пока приложение открыто: `UIApplication.shared.isIdleTimerDisabled = true` в `iosApp.swift` — прошивка блока идёт 15–20 мин, автоблокировка приостанавливала приложение, и блок сбрасывал приём (`ERROR_TIMEOUT`).
- `Info.plist`: `UIBackgroundModes = bluetooth-central` — BLE-сессия и прошивка продолжаются в фоне и при заблокированном экране (события CoreBluetooth будят приложение). При ревью App Store режим обосновывается настройкой и прошивкой своего оборудования.
- `PRODUCT_BUNDLE_IDENTIFIER = ru.alarmtrade.specialist` — приложение старого «Pandora Specialist» в App Store (Apple ID 1563735964): SpeCMP встаёт поверх него; подпись — командой старого приложения (`TEAM_ID`).
- Версию не задавать в `Info.plist`/`Config.xcconfig`: её пишет в собранный `Info.plist` шаг «Set App Version» (`scripts/set-app-version.sh`) из `gradle/libs.versions.toml` — одна версия на все платформы.
- `Info.plist`: `NSMotionUsageDescription`, `NSContactsUsageDescription`, `NSLocationWhenInUseUsageDescription` обязательны, хотя на iOS эти данные не используются: на них ссылается `permissions-common` (alarmtrade-common3), и без строк App Store Connect отклоняет сборку при обработке (ITMS-90683). Не удалять.
- `Info.plist`: `ITSAppUsesNonExemptEncryption = false` — шифрование только стандартное системное (HTTPS/TLS), App Store Connect не спрашивает export compliance у каждой сборки. Появится своя криптография — пересмотреть.
- Push: `AppDelegate.swift` (`@UIApplicationDelegateAdaptor`) — `FirebaseApp.configure()`, делегат `UNUserNotificationCenter` (до конца запуска — иначе тап, запустивший приложение, теряется), `registerForRemoteNotifications`, APNs-токен → `Messaging.apnsToken`; `FirebasePushMessaging` отдаёт FCM-токен в Kotlin (`PushBridge`), ждёт регистрации APNs. Пакет `firebase-ios-sdk` (SPM, продукт `FirebaseMessaging`) — в `project.pbxproj`. `GoogleService-Info.plist` — проект `pandora-specialist-6663f`. `iosApp.entitlements` (`aps-environment`, в `membershipExceptions` синхронизированной группы), `UIBackgroundModes` += `remote-notification` (data-push без alert будит приложение — показ своим уведомлением). Разрешение на уведомления спрашивает общий код на главном экране.
