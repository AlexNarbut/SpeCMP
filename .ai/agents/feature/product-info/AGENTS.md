# feature/product-info

- Обособленная фича **«Информация о товаре»**: по ID устройства или цифрам штрих-кода — товар (название, ID, серийный номер, заводская дата, прошивки) и комплект (название, серийный номер, дата упаковки, компоненты). domain + data + presentation в одном модуле; ассистент (`feature/mount-assistant`) ходит через свой порт `AssistantProductRepository` с адаптером `composeApp/assistant/AppAssistantProductRepository` (`find` + `isEnabled`), напрямую модуль не подключает. ТЗ — `.claude/tasks/product-info.md`, макет — `design/features/product-info/`.
- Точка входа — `ProductInfoRoute(query, connectedId)` + `ProductInfoEntry(onBack, query, connectedId)` (`presentation/navigation`), маршрут поверх текущего графа в `composeApp/navigation/AppNavigation.kt`: карточка главного `MainHomeAction.ProductInfo` → без номера; кнопка в шапке блока расширенного монтажа (`AdvancedMountRootEffect.OpenProductInfo(systemId)` → `onOpenProductInfo`) → `query = connectedId = systemId`, сессия с блоком остаётся открытой. Видимость входов — фича пользователя `UserAppFeature.PRODUCT_SEARCH` (проверяют входы, экран — нет).
- **SDK** — `DeviceInformationInteractor.getDevicePackageInformation` (`GET Api/Packages/Find?deviceId=`) через `data/datasource/ProductInfoDataSource`. SDK заворачивает **любую** ошибку в `DevicePackageInformationNotFoundException`: `SpecialistProductInfoRepository` разворачивает `cause` — сеть, таймаут и ошибка сервера идут как `AppException` (`ApiError`), остальное (в т.ч. неразобранное тело — так сервер отвечает на неизвестный номер, проверить на живом ответе) — `ProductNotFoundException(id)`. Пустые `name`/`serial` SDK → `null`, даты — только дата (`LocalDate`).
- **Поиск — по явной команде** («Найти», IME Search): сервер ищет по точному номеру. `ProductQuery.parse` убирает пробелы и дефисы, номер — только цифры и влезает в `Long` (ошибки `EMPTY`/`NOT_DIGITS`/`TOO_LONG` под полем, без запроса). Номер из маршрута ищется в `onStart`. Новый поиск отменяет прежний (`launchReplacing`).
- «Подключённый блок» — `ProductInfoState.isConnectedUnit`: ID найденного товара == `connectedId`, а не текст поля. Компоненты: Compact/Medium — строки с раскрытием (`expanded` в state, «Раскрыть все»), Expanded (≥ 840) — таблица и «Товар» | «Комплект» в две колонки; max-width 720 / 1040.
- Копирование ID и серийников — в `ProductInfoEntry` (`LocalClipboardManager` + снекбар), VM не участвует.
- Строки — `productinfo_*` (`core/localization/*/productinfo.xml`, plurals для числа компонентов и прошивок); `testTag` — `ProductInfoTags` (`productinfo_query|search|clear|product|kit|connected|expand_all|error|retry`, `productinfo_component_<i>`).
- Сканер штрих-кода (Android, iOS) — следующий этап, модуль `core/barcode` (ТЗ, п. 3.6).
- После изменений: `:feature:product-info:jvmTest`, сборка из `.ai/rules.md` → «Validation».
