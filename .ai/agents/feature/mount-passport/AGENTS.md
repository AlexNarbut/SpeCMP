# feature/mount-passport

- Обособленная фича **«Паспорт монтажа»**: список паспортов блока, архив (все + поиск), предотчёт (редактируемый паспорт). domain + data + presentation в одном модуле; потребителей логики вне модуля нет. ТЗ — `.claude/tasks/mount-passport.md` (раздел «Реализация — решения владельца 2026-11-20» главнее), макет — `design/features/mount-passport/` (`PassportList.jsx`, `PassportEditor.jsx`, вариант 2a).
- **Вся бизнес-логика — в SDK** (`MountPassportInteractor`, `alarmtrade-common3` `specialist` ≥ 1.2.22): хранение папками, индекс и поиск (нормализация госномера/VIN/телефона), номер, запоминание организации/адреса, лимит 8 фото. Фича её не дублирует: `data/datasource/MountPassportDataSource` — только делегирование, `SpecialistMountPassportRepository` — запросы, маппинг SDK → domain (пути фото — абсолютные: папка из `getFiles` + относительный путь SDK) и ошибки фото: `MountPassportPhotoLimitException` → `PassportPhotoLimitException`, нехватка места (`ENOSPC`/«No space left» в цепочке причин — SDK её не различает) → `PassportStorageFullException`.
- «Мои конфигурации» — порт `PassportConfigurationsRepository` (фича от `feature/configurator` не зависит), адаптер `composeApp/mountpassport/AppPassportConfigurationsRepository` (`LocalConfigurationsRepository.create(…, SettingsSource.File(settings.dxs, inPlace = false))`), модуль `mountPassportPortsModule`. «Сохранить в файл» — общий `SettingsFileSaver` (`feature/device/presentation-core`) по пути `settings.dxs` из `getFiles`.
- **Входы** (`presentation/navigation/MountPassportEntries.kt`): маршруты `MountPassportArchiveRoute` / `MountPassportUnitRoute(systemId)` / `MountPassportEditorRoute(passportId)` и `MountPassportArchiveEntry` / `MountPassportUnitEntry` / `MountPassportEditorEntry(…, callbacks, ports)`; внутри — свой nav3-граф (`MountPassportNavGraph`: список → предотчёт). `MountPassportCallbacks` — переходы наружу: `onNewPassport(systemId)`, `onNewWithoutUnit`, `onFinish(id)` («Дооформить» заготовку), `onReread(id, stage)`, `onReadUnit(id)` («Считать блок» у паспорта без блока), `onCreatePdf(id)`; `MountPassportPorts` — `ImagePicker` и `SettingsFileSaver` из корня. Обвязка в корне — `composeApp/navigation/MountPassportWiring.kt` (колбэки считывания/PDF пока не подключены).
- **Список** (`PassportListViewModel`, `BaseDeviceViewModel`): архив — `observeAll`, блок — `observeUnit(systemId)`; поиск — поле state + `select { query }` с debounce 300 мс (пустой запрос — сразу), `flatMapLatest` отменяет прежний поиск, при изменении архива поиск повторяется. Подсветка совпадения — `presentation/model/SearchHighlight.kt` (только место в тексте: без регистра, пробелов и разделителей, «ё» = «е», латинские двойники кириллицы); строка «VIN/Клиент/Телефон: …» — когда совпадение не в заголовке строки. «Дооформить» — `BLANK` и подключён тот же блок (`canFinish`), иначе подсказка. Объём хранилища — строкой в архиве без запроса. Удаление — диалог подтверждения. Раскладки: Compact/Medium (по центру 720) — одна колонка, предотчёт отдельным экраном; Expanded (≥ 840) — список 400 dp + справа предотчёт выбранного (заготовка — карточка «Дооформить»).
- **Предотчёт** (`PassportEditorViewModel`): аккордеон секций в порядке документа (`sections()`: «Проверка» — только с заданиями, «Устройства» — не у паспорта без блока), раскрытие — локальное UI-состояние. Ручные поля — `PassportForm` в state; правки пишутся одной записью `edit` после паузы 700 мс (`launchReplacing(SAVE)`), признак `SaveStatus` в шапке; «Назад» дописывает несохранённое (`onBack` → `Close`) без подтверждения. Валидация (`PassportEditorTransitions.kt`): VIN — 17 символов без I/O/Q (ошибка длины — когда поле не в фокусе), пробег — цифры, телефон — `PhoneNumbers.isValid`; неверное значение не пишется — остаётся прежнее. Работы — галочками у расширенного монтажа и паспорта без блока, только чтение у быстрого монтажа. «Перечитать» — только при подключённом том же блоке (`rereadVisible`), этапы `NOT_READ`/`SKIPPED`. Фото: камера/галерея (desktop — файл), `PermissionsProvider.requestCameraPermission()`, отказ → лист «Открыть настройки»; JPEG ≤ 2048 — `ImagePicker.pick`, миниатюра 320 — `prepare(…, maxSide = 320)`; лимит 8 проверяется до пикера; просмотр на весь экран (листание, подпись ≤ 60 символов с debounce, удаление с подтверждением).
- Строки — `mountpassport_*` (`core/localization/*/mountpassport.xml`); `testTag` — `MountPassportTags`. Галерея состояний — `MountPassportGallery` (`build/state-gallery/mount-passport`).
