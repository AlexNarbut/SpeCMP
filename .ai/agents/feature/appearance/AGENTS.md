# feature/appearance

- Область: экран «Оформление» — пользовательская тема (светлая и тёмная): готовые темы, 12 цветов с проверкой контраста, фон (свечение / заливка / градиент), размер текста, скругления, заливка/форма/отступы кнопок и чипов, экспорт/импорт `.json`. Макет — `design/features/appearance/`. Вход — главная → боковое меню → «Оформление» (`AppearanceRoute`, `AppearanceEntry(onBack, filePicker, fileSaver)` в `composeApp/AppNavigation`). `flasherApp` экрана не имеет.
- Обособленный модуль без domain/data: модель темы, контраст (`ThemeContrast`), готовые темы и формат файла (`ThemeFileCodec`) — в `core/ui/theme/custom`, хранение — `CustomThemeStore` (`core/ui`). Свою проверку контраста фича не пишет; база проверок — `ThemePreset.Default.mode(isDark)` (`contrastBase`).
- Зависимости VM: `CustomThemeStore` (Koin `single { DefaultCustomThemeStore }` в `composeApp/di/AppServicesModule` — тот же объект, что у `AppTheme`, поэтому «Применить» сразу перекрашивает приложение), `AppDispatchers`, порты `TextFilePicker`/`TextFileSaver` (`core/files`, создаёт корень `rememberTextFile*(dispatchers)`) и тема приложения при входе (`isDark`) — через `parametersOf`.
- `AppearanceViewModel`: state — применённая тема, черновик, выбранная тема (вкладка Светлая/Тёмная, по умолчанию — текущая), «Одинаково для обеих тем» (`linked`, начально `light.sameShapeAs(dark)`), «Все параметры», редактор цвета. Чистые переходы — `AppearanceTransitions.kt` (тестируются без VM). Цвета и фон меняются в выбранной теме; размеры, форма, кнопки и чипы — в обеих при `linked`, иначе в выбранной. Включение `linked` копирует форму выбранной темы в другую, заливку — только если она там проходит контраст. Градиент: не проходит второй цвет — подбирается ближайший, не подобрать — заливка. Заливка кнопок недоступна, если `ThemeContrast.canUseFill` ложно хотя бы в одной из целевых тем.
- Редактор цвета: HEX, быстрые образцы и палитра (`ThemeSwatches`), пипетки нет; «Готово» заблокировано, пока HEX неверный или проверка не проходит; «Подобрать» ставит `ThemeContrast.nearest`. Шторка на Compact, диалог на широком окне.
- «Применить» — `store.save(draft)` на `io` + снекбар; «Отменить» — черновик = применённая. Экспорт — `ThemeFileCodec.encode` → `TextFileSaver` (`pandora-theme.json`), отмена без сообщения; импорт — `TextFilePicker` → `decode(text, base = draft)`: не файл темы / загружено / исправлено N цветов / цвета сброшены.
- UI: экран в применённой теме, черновик — только в предпросмотре (`CmpThemeProvider(draft.mode(isDark), isDark)` + `Modifier.cmpPageBackground()`) и образцах вариантов (цвета пользователя рисуются `ThemeColor.toColor()`). Compact — колонка, предпросмотр сверху; Medium+ — настройки слева, предпросмотр справа (320/400 dp), ширина до 1040. Панель «Отменить/Применить» — под содержимым.
- Строки — префикс `appearance` в `core/localization`. Галерея состояний — `./gradlew :feature:appearance:jvmTest --tests '*AppearanceGallery*'` → `build/state-gallery/appearance`.
