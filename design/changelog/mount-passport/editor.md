Чат: «Паспорт монтажа». ТЗ — `uploads/mount-passport-design-brief-87e542bb.md`. Описание фичи — `features/mount-passport/README.md`.

## Добавлено — `features/mount-passport/`
- **Предотчёт** `PassportEditor.jsx`. Выбран вариант 2a из `PassportEditorOptions.html` (сравнение 2×2 сохранено как история):
  аккордеон — секции свёрнуты, итог в строку, «Автомобиль» открыт; «само» — карточки с источником («Считано с блока»,
  «Из мастера монтажа», «Из профиля»); ручные поля — с подписью «Необязательно». 10 секций в порядке документа, сценарии
  быстрый / расширенный / часть не прочитана / без блока, «Перечитать», признак «Сохранено», закреплённая «Сформировать PDF»,
  снимок настроек «В документ не попадают».
  - Без подключённого блока (архив) правятся только ручные поля, «Перечитать» скрыто.
  - Паспорт без блока + подключён блок с этим ID → «Считать блок».
  - Фото: сетка, «Камера / Галерея» (desktop — файл), нет доступа к камере → «Открыть настройки», загрузка, 8 из 8,
    просмотр на весь экран (листание, подпись в одну строку, удаление с подтверждением), нет места на устройстве.
- **Считывание блока** `PassportRead.jsx`: 5 этапов, все состояния п. 3 ТЗ; «Пропустить» у «Настроек»; стоп-состояния
  «Не удалось прочитать блок», «Связь с блоком потеряна», «Блок не на связи».
- **Паспорт готов** `PassportReady.jsx`: листы, «Стр. N из M», «Формируем документ…», ошибка, «Поделиться» (desktop —
  «Сохранить файл»), «⋯» → экспорт ZIP и настройки блока, снекбары.
- **Документ A4** `PassportDoc.jsx` + `PassportDocument.html`: поля 15 мм, ч/б, акцент #2C3639, IBM Plex Sans, 3 размера.
  Полный (3 стр.), минимальный, без блока, длинный (30 заданий, 8 фото, 4 стр., перенос таблицы с повтором заголовка), RU/EN,
  живой вариант для предпросмотра (только заполненное).
- **Список / архив** `PassportList.jsx` (`PassportApp`, `PassportWorkspace`): раздел расширенного монтажа и архив; поиск с
  подсветкой; статусы «Не оформлен» / «Черновик» / «Оформлен»; «Дооформить»; удаление; все пустые состояния; экран «Блок»
  (паспорт без блока: найден / не найден / нет интернета / ошибки поля).
- **Перенос** `PassportTransfer.jsx`: ZIP = PDF + `passport.json` + `settings.dxs` (вкл.) + фото в полном качестве 2048 px
  (выкл.). Экспорт одного, выбранных, всех; импорт: файл → сводка → дубликаты «Пропустить / Заменить» → «Импортирован»;
  ошибка «Это не архив паспортов». Compact — лист снизу, medium+ — диалог.
- **Хранение**: «128 паспортов · 340 МБ на этом устройстве»; ежемесячно «Сохраните копию архива» → «Экспорт всех» / «Позже».
- **Раскладки** (M3 Window Size Classes): compact — экраны по очереди; medium — колонка по центру; expanded — список +
  паспорт, редактор = поля слева + живой лист справа; низкое окно (< 520) — над листом главная кнопка + «⋯».
- Хосты: `MountPassport.html`, `MountPassportTablet.html` (1280×800, 800×1280, 915×412), `MountPassportDesktop.html`
  (1280×800, 800×600); демо-панель `mp-host.jsx`. Иконка раздела `passport` — `res/icons/section-icons.js`.

## Решения владельца в ходе работы
- Устройства системы читаются и по USB (динамическая таблица) — список без адресов.
- У устройств — версия ПО (в предотчёте и столбец «Версия ПО» в документе).
- Нужен перенос архивом на другой компьютер (экспорт / импорт ZIP).
- Хранение локальное: папка `passports/<№>/` — `passport.json`, `settings.dxs`, `photos/` (2048 px, JPEG 80, EXIF-поворот
  применён, геометки удалены), `thumbs/` (320 px), `Паспорт.pdf` (кэш); индекс SQLite. Android `filesDir`, iOS Application
  Support, Desktop — папка данных приложения ОС; запись temp → rename. Экспорт ZIP — резервная копия.
