## Что изменилось
- Новая фича `features/home/` — главный экран приложения по ТЗ `uploads/design-brief.md`.
- Топбар (64dp): слева кнопка меню, по центру `Pandora Спец`, справа статус `База обновлена`
  (на compact — только иконка; при синхронизации — спиннер + `Обновление…`).
- Боковое меню/drawer: сразу профиль (аватар/имя/email, поддержка неполного профиля),
  переключение темы, обновление базы, настройки, выход; версия ПО внизу. Без заголовка «Меню»,
  без крестика. Compact/Medium — modal со scrim; Expanded/Large — боковая панель.
- Два равнозначных основных сценария: `Быстрый монтаж` / `Расширенный монтаж`
  (крупные action-карточки, только иконка+название+описание, без нижних CTA).
- Сетка вспомогательных инструментов без заголовка: Конфигуратор, Архив прошивок, Автомобили,
  Заявки, Обратная связь, Информация о товаре. `Статьи` не отображаются.
- Адаптив по Window Size Classes: Compact 1 кол / Medium 2 / Expanded 3 / Large 4 (инструменты);
  основные карточки 1 кол (compact) → 2 кол (шире).
- 2 варианта основных карточек: `centered` (иконка сверху по центру) и `leading` (иконка слева).
- Состояния карточек: default / hover / focus / pressed / disabled; loading синхронизации.
- Состояние загрузки экрана: скелетон-плейсхолдеры в раскладке карточек (перестраиваются по
  брейкпоинтам) + тонкий linear progress под топбаром; статус и меню на время загрузки скрыты.
  Показывается при входе (~1.5с), в макетах есть кнопка «↻ Загрузка» для повтора.
- На desktop в боковом меню — вход в обновление приложения (строка «Проверить обновления» и блок
  «Доступна новая версия» внизу бара), открывающий раздел обновления. Сам экран обновления вынесен
  в отдельную фичу — см. changelog по `app-update`.
- Deliverables: Home.html (phone), HomeTablet.html, HomeDesktop.html (Expanded/Large + меню),
  HomeParts.html (все компоненты по отдельности + галерея состояний).

## Зачем
Главный экран как спокойная рабочая панель: два сценария сверху, инструменты ниже,
системные действия в меню, статус данных в топбаре — по ТЗ.

## Заметки
- Иконки основных карточек и инструментов — реальные SVG из старого проекта (`main_*`),
  инлайнятся через `res/icons/main-icons.js` (наследуют `currentColor`, адаптируются к теме).
  Двухцветные `fast_mount`/`adv_mount` восстановлены: базовые слои opacity .3, деталь — полный тон.
  Полный набор иконок старого проекта скопирован в `res/icons/legacy/`.
- Иконки чрома (меню, тема, синхронизация, настройки, выход, статус) — лигатуры Material Icons.
- Всё построено на Cmp*-компонентах и токенах дизайн-системы, светлая и тёмная темы.
