## Что изменилось
- K1: поиск по названию и описанию, чип-фильтр по модели, карточки (название, модель, дата, описание 2 строки), меню ⋮, подгрузка порциями, пусто / ничего не найдено / загрузка / ошибка, «Создать» → С нуля / Из облака / Из файла / Из подключённого блока. Широкое окно — список + карточка выбранной.
- K2: недавние и подключённый блок сверху, поиск, загрузка, ошибка с «Повторить». K3: момент системного выбора → модель (последняя подставлена) → редактор; ошибки «повреждён» и «не подходит для модели».
- K4: каталог «Автомобили с конфигурациями» → список (рейтинг «★ 4 · 8», «Лучшие / Новые», фильтр модели, пометка «Нужна прошивка …») → карточка: описание «Показать полностью», монтажная карта, вложения с просмотром, CAN-предупреждение с переходом к прошивке, действия «Записать в блок» / «Открыть настройки» / «Сохранить в мои». Пусто, нет сети, ошибка.
- K5: шапка редактора — название + плашка источника + модель + «Только просмотр»; панель «Сохранить» / «Сохранить как…»; меню по таблице ТЗ; выход с несохранёнными.
- K6: шторка «Мои конфигурации / Файл», форма (название 1–50 обязательно, описание до 500 необязательно со счётчиком, модель только для чтения), прогресс, тост с «Открыть», ошибка с «Повторить»; та же форма — для переименования.
- K7: «Загрузить из…» → мои (только модель блока) / облако / файл / заводские → K9 → «Загрузка настроек…» → редактор с подсветкой и тостом. Ошибки: не подходит, повреждённый файл, CAN-код.
- K9: итог одной строкой, предупреждение о незаписанных правках, разделы с числом изменений, «было → станет», входы/выходы «+ Капот, − Багажник», CAN-код первой строкой, поиск при > 20; совпадают / сравнение / ошибка; на широком — колонки.

## Зачем
В старом приложении не было поиска и фильтров, конфигурация уходила в блок без подтверждения и без показа изменений, иконки «Загрузить / Выгрузить» путались, облачную конфигурацию нельзя было посмотреть до применения.

## Окна и темы
- Compact 412×840 (Configurator.html), планшет 800×1280 / 1280×800 (ConfiguratorTablet.html), Desktop 1280×800 / 800×600 / 1600×900 (ConfiguratorDesktop.html); светлая и тёмная темы.
- Medium/Expanded: master-detail в K1 и K4, K9 — диалог 820 px с колонками «№ / Настройка / Было / Станет»; Compact — полноэкранный K9, шторки вместо поповеров.
- ConfiguratorStates.html — все сценарии K1–K9 сеткой в выбранном окне; ConfiguratorParts.html — новые компоненты кита в light и dark рядом.
- Витрина: переключатели «Блок подключён / нет», «Записать» скрыт / неактивен, облако ОК / загрузка / ошибка / нет сети, файл исправен / повреждён / другой модели, сохранение успех / ошибка, правки в блоке есть / нет.

## Заметки
- «Записать в блок» без блока / другой модели — показаны оба варианта (скрыт / неактивен с пояснением), выбор за командой.
- Рейтинг заложен как «★ 4,5 · 12» — шкала уточняется у бэкенда.
- Данные демонстрационные; значения конфигураций — патчи к настройкам демо-блока.
- Фильтр «Модель блока» вынесен на список облачных конфигураций (каталог автомобилей — общий экран vehicle-select, точка E).
- Системные окна выбора/сохранения файла не рисуются — показан момент вызова (пунктирная заглушка).
- Слияние в финальную запись не выполнялось — черновик остаётся в `changelog/configurator/`.
