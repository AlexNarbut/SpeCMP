## Что изменилось

### Новая фича auth-flow (по `uploads/designer-requirements.md`)
- Пять экранов со всеми состояниями:
  - **Auth Root** — loading (тихий индикатор без текста про проверку), error (с retry).
  - **Login** — empty / partial / ready / loading / error / activation-required (диалог поверх логина).
  - **Registration** — empty / partial / ready / loading / validation / server error / success.
  - **Forgot Password** — empty / ready / loading / error / success.
  - **Logged-in placeholder** — logged in / logout loading / logout error.
- EN/RU с переключателем `LangSegment` в топ-баре; смена языка НЕ очищает форму (EN — fallback).
- Адаптив по Material 3 Window Size Classes: Compact (одна колонка), Medium (центрированная
  карточка), Expanded (двухколоночная: бренд-рейл + карточка формы).
- Каркас только из UI Kit: `CmpTopAppBar`, `CmpIconButton` (back — иконка `ArrowBack`),
  `CmpTextField`, `CmpButton`, `CmpOutlinedButton`, `CmpTextButton`, `CmpCheckbox`, `CmpDialog`,
  `CmpCircularProgressIndicator`, `CmpLinearProgressIndicator`, `CmpCard`, `CmpText`, `CmpIcon`.
- Архитектура: `i18n.js` (словарь), `AuthScreens.jsx` (презентационные экраны + shell),
  `Auth.jsx` (`AuthFlow` — живой интерактив со скриптованной асинхронностью + `AuthPinned` —
  рендер любого экрана в конкретном состоянии; `AUTH_STATES` — каталог состояний).
- Обёртки устройств: `Auth.html` (Android Compact), `AuthTablet.html` (портрет 800×1280 /
  ландшафт 1280×800), `AuthDesktop.html` (окно 1280×800). Плюс `AuthStates.html` — галерея всех
  состояний (EN/RU, light & dark) и `AuthFlow.html` — диаграмма потока. Навигация через `res/nav.js`
  (ключи `auth`, `auth-tablet`, `auth-desktop`, `auth-states`, `auth-flow`); ссылка с `index.html`.

### Композиция (ревью «слишком просто/по-материалу»)
- Слоистый брендовый фон `AuthBackdrop`: мягкие радиальные «блики» из `--primary-container` и
  `--tertiary-container` поверх `--background` (роли адаптируются под тему).
- «Парящая» карточка формы: `--surface` + тень (elevation 2) + тонкая граница, радиус 28,
  padding 28. Подложка темнее карточки — карточка визуально приподнята; вырез подписи поля
  (`--surface`) совпадает с фоном карточки.
- Hero-зона с реальной иконкой приложения `features/auth/app-icon.png` (gear + lock) + крупный
  wordmark. На Expanded — двухколоночная раскладка, содержимое бренд-рейла центрировано внутри
  колонки (иконка, заголовок, подзаголовок, акцент-черта), весь блок центрирован в окне.
- Крупные CTA 52dp со скруглением 16 (под «толстые пальцы» монтажника).
- Мягкая входная анимация карточки (fade/slide-up), гасится под `prefers-reduced-motion`.
  Топ-бары прозрачные — фон идёт под ними.
- Креативная дирекция закреплена в `design-system/SKILL.md` (дизайнер уровня Apple: актуально,
  живо, удобно — в рамках токенов и обеих тем).

### Доводка по ревью
- **Спиннер загрузки** (`CmpCircularProgressIndicator`, общий компонент ДС): вращение перенесено
  с внутреннего `<circle>` на внешний `<span>`. Раньше `transform-origin: center` у SVG-фигуры
  считался от угла вьюпорта (0,0), и дуга «облетала» по большой окружности вместо вращения на
  месте; keyframe — полный оборот 0→360°.
- **Боковые отступы карточек**: `CmpCard` по умолчанию `box-sizing: content-box`, из-за чего
  `width:100%` + padding 28×2 перерастал контейнер и карточка упиралась в края экрана. Карточкам
  добавлен `box-sizing: border-box`; боковой отступ контейнера — 24px (симметричные зазоры ~25px).
- **Ритм форм**: главная кнопка отделена от полей зазором 24px, ссылка «Forgot password?» —
  вплотную к полю пароля (4px); базовый шаг между полями 16px.

## Зачем
Реализовать полный auth-flow для специалиста-установщика (вход / регистрация / восстановление /
logged-in placeholder) по бизнес-требованиям дизайнера: понятный без обучения, один сценарий на
экран, EN/RU, обе темы, крупные зоны касания. Последующие правки — по ревью пользователя
(оживить композицию, починить спиннер и отступы, центрировать содержимое на десктопе).

## Заметки
- **Кандидаты в UI Kit** (собраны из примитивов, отдельные `Cmp*` не вводились): **PasswordField**
  (`CmpTextField` + trailing visibility `CmpIconButton`) и **LangSegment** (сегмент EN | RU).
- **iOS-обёртка не делалась** — выбраны Android / планшет / Desktop. Можно добавить при необходимости.
- Поведение прототипа скриптовано: login — email с «fail» → ошибка, «new»/«activate» → диалог
  активации, иначе вход; registration — невалидные поля → validation, «fail» → server error, иначе
  success; forgot — «fail» → error, иначе success; logout всегда успешен.
- Фикс спиннера затрагивает всю дизайн-систему (общий компонент).
- Инструмент захвата скриншотов (html-to-image) не рисует иконочный шрифт и заливку карточек —
  корректность проверялась замерами реального DOM; в живом превью всё отрисовывается.
