- features/advanced-mount/AdvancedMount.jsx, AdvancedMount.html, AdvancedMountTablet.html, AdvancedMountDesktop.html

## Иконки разделов

Пять новых иконок. Стиль — как у остальных плиток «Расширенного монтажа» и главной: сетка 24 dp, заливка цветом контента (`currentColor`), двухтонная (базовый слой с прозрачностью 0.3, деталь полным тоном). Рисуются inline, чтобы перекрашивались темой.

| Ключ | Раздел | Что изображено | Было |
|---|---|---|---|
| `adv_settings` | Расширенные настройки | Панель с тремя ползунками | Иконка «Конфигуратора» — разделы путались |
| `tech_requests` | Заявки на техпомощь | Лист заявки + круг с трубкой (обратный звонок) | `orders` (общая «заявки») |
| `clone` | Процедура Clone | Два ключа, тот же ключ, что у «Бесключевого обхода» | Два листа (копирование) |
| `sys_devices` | Устройства системы | Метка/брелок с волнами сигнала | Радиоволны без устройства |
| `pairing` | Приживление устройств | Та же метка + «плюс» | Телефон с волнами |

Где используются:
- «Расширенный монтаж» — плитки `settings`, `tickets`, `clone`, `devices`, `extra` (карта `SECTION_MAP` в AdvancedMount.jsx);
- главная — инструмент «Заявки» переименован в **«Заявки на техпомощь»** («Обратный звонок специалиста и история заявок»), иконка `tech_requests`, ведёт на экран заявок (раньше вёл в чат).

Для разработки: SVG-разметку брать из `res/icons/section-icons.js` и завести как векторные ресурсы (Compose `ImageVector` / Android vector drawable) с `tint = LocalContentColor`. Слой с `opacity=".3"` — тот же цвет с альфой 0.3. У `tech_requests` трубка вырезана маской из круга — в векторе это отдельный путь с `fillType = EvenOdd` или вычитание.

## «Проверка состояния»: раскладки для раскладных, планшетов и телефона-ландшафта

Раскладка выбирается по **ширине и высоте окна** (не по типу устройства). Компоненты те же, меняется только компоновка.

| Окно | Пример | Раскладка |
|---|---|---|
| ширина < 600 | телефон, раскладной сложен 344×882 | Без изменений: статус + вкладки «Проверки / Пульт / Подробно» |
| высота < 520 и ширина ≥ 600 | телефон-ландшафт 915×412 | **Низкое окно** |
| ширина 600–1099 | раскладной разложен 690×829 и 829×690, планшет-портрет 800×1280 | **Две панели** |
| ширина ≥ 1100 | планшет-ландшафт 1280×800, Desktop | **Три колонки** |

### Две панели (раскладной разложен)
- Панели **равные**, граница — ровно по сгибу (`hingeAt` = половина ширины; на реальном устройстве — граница из `WindowLayoutInfo` / `FoldingFeature`).
- Слева всегда видно «живое»: карточка статуса (охрана, «на связи · N с»), баннеры режимов, машина сверху, активные зоны чипами, показатели.
- Справа вкладки: **«Проверки N/M»** (только быстрый монтаж) · **«Команды»** · **«Подробно»** (зоны плитками, двигатель, связь, дополнительно).
- В быстром монтаже чек-лист и машина видны одновременно — монтажник открывает дверь и сразу видит, как отметилось задание.
- «Далее» — в нижней панели под правой половиной.
- Горизонтальный сгиб (829×690) — та же раскладка; колонки прокручиваются независимо.
- Раньше: при 690 dp экран считал себя телефоном (вкладки, половина экрана пустая, сгиб резал машину); при 829 dp показатели вставали в один столбец.

### Три колонки (планшет-ландшафт)
- Колонки: машина + показатели (300–340) | все зоны без вкладок + двигатель, связь | команды (расширенный) или чек-лист (быстрый) (340–400).
- Каждая команда показывается один раз (раньше — квадраты в пульте и полный список справа).
- В быстром монтаже команды не мешают чек-листу: кнопка «Команды блоку» в левой колонке открывает лист со всеми командами.

### Низкое окно (телефон-ландшафт)
- Карточки статуса нет: статус — пилюля в шапке («Снято с охраны · 2 с», цвет по состоянию).
- Слева: машина боком, активные зоны, показатели.
- Справа: расширенный — 6 крупных команд + «Подробно: зоны, двигатель, связь» (лист); быстрый — «Проверка N из M», прогресс, **текущее задание** и «Далее», полный список — лист «Весь список».

### Где включено
- `CheckStateScreen` по умолчанию рисует новые раскладки (`layoutV="v2"`); `layoutV="v1"` — прежние, только для сравнения.
- Действует везде, где используется экран: «Расширенный монтаж» (`CheckState*.html`) и шаг «Проверка состояния» в быстром монтаже.
- Новые страницы: `CheckStateFoldable.html` — раскладной в трёх положениях; `CheckStateLayouts.html` — «сейчас / предложение» рядом для всех окон.

## «Проверка прошивки»: карточки модулей на раскладном и планшете

Проблема (фото с раскладного, 690 dp): сетка всегда делилась на 2 колонки, поэтому один модуль занимал левую половину, правая пустовала; в узкой карточке переносились название модуля, «Доступно обновление» и подпись кнопки («Описан / ие»).

Новая логика по классу окна:

| Окно | Карточки |
|---|---|
| Compact < 600 | Как раньше: обычные карточки столбиком |
| Medium 600–839 (раскладной 690×829, планшет-портрет) | **Широкие** карточки столбиком на всю ширину |
| Expanded ≥ 840, несколько модулей | Обычные карточки в 2 колонки |
| Expanded ≥ 840, один модуль | Одна **широкая** карточка на всю строку |

Широкая карточка (`ModCardWide`), две колонки:
- слева — тип модуля, название (`titleLarge`), «Версия ПО», текстовая «Проверить заново» (вместо иконки ↻ в углу);
- справа — статус. При обновлении: «Доступно обновление», переход версий «3.57 → 3.61», **первые 3 строки описания** прямо в карточке, «Полное описание» (открывает прежний диалог), крупная «Обновить» 52 dp. «Актуальная» / «Не поддерживается» / ошибка — по центру правой колонки.
- Отдельная кнопка «Описание» в широкой карточке не нужна: начало описания видно сразу.

Во всех кнопках карточек — `whiteSpace: nowrap` (подписи больше не рвутся).

Демо: `FirmwareFoldable.html` (`psGo('firmware-foldable')`), сценарий «Один модуль» — как на фото.

## Заметки
- Зоны касания ≥ 48 dp сохранены во всех раскладках; квадраты команд — 72 dp.
- Ориентир раскладного — Galaxy Z Fold (344×882 / 690×829). Другие модели попадают в те же диапазоны ширины.
