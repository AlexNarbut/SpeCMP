# 2026-07-14 — Точка входа: проверка авторизации в index (черновик-фрагмент)

**Экраны:** index, auth, home
**Файлы:** index.html, index-tablet.html, index-desktop.html, res/nav.js,
features/auth/Auth.jsx, features/home/Home.jsx

## Что изменилось
- `index.html` — теперь точка входа приложения: если сессии нет (`localStorage["ps-authed"]`),
  открывается auth flow (проверка сессии → вход); если есть — главный экран.
- Успешный вход сохраняет сессию и открывает главный; «Выход» в меню главного
  (и кнопка «Сбросить сессию» в тулбаре) очищает сессию и возвращает на авторизацию.
- `AuthFlow` — новый необязательный проп `onLoggedIn` (вызывается вместо экрана-заглушки
  loggedIn); `HomeApp` — новый необязательный проп `onLogout`.
- Та же проверка авторизации на планшете и Desktop: `index-tablet.html`
  (800×1280 / 1280×800) и `index-desktop.html` (1100×760 / 1280×800, тайтл-бар);
  сессия общая для всех трёх точек входа. Ключи `res/nav.js`: `index-tablet`,
  `index-desktop`.

## Зачем
Запрошено поведение реального приложения: index проверяет авторизацию и открывает
auth flow либо main feature.

## Заметки
- Сессия — мок в localStorage; в приложении — реальная проверка токена.
- Хосты Auth.html / Home.html не изменились (поведение прежнее, пропсы опциональны).
