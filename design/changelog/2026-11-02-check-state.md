## Что изменилось

### Каркас
- Шапка «Проверка состояния» · «Модель · ID блока», «Назад».
- Телефон (<760): сверху всегда виден главный статус + предупреждения, ниже вкладки «Пульт / Подробно» (в быстром монтаже первой идёт «Проверки N/M»).
- Широкое окно (≥760): слева статус + пульт (+ чек-лист), справа «Подробно»; в быстром монтаже «Далее» под правой колонкой.

### Пульт (первая вкладка, как в старом приложении)
- Пульт: лента показателей с подписями (автозапуск с отсчётом, обороты, сеть, температуры, топливо, GSM, GPS; отсутствующие скрыты) → силуэт машины со статусами-пиктограммами → колонка основных команд рядом с машиной («Охрана», «Снять», «Запуск»/«Стоп», «Багажник», «Паника», удержание 1 с) и «Все команды».
- Под машиной — подписанные плашки активных и только что изменившихся зон («Передняя левая дверь: открыта»); если ничего — «Всё закрыто, датчики в норме».
- «Подробно»: зоны (A — список / B — схема), двигатель, связь, «Дополнительно», все команды.

### Без «прыжков» и прогресс на иконке
- Строка «Ждём ответа блока / Блок выполнил» убрана из статуса — экран не сдвигается. Прогресс команды — кольцом вокруг иконки: удержание — заполняющееся кольцо, отправка — вращающееся; итог — на кнопке + снэкбар поверх.
- Плашки активных зон под машиной — одна строка фиксированной высоты с горизонтальной прокруткой.
- «Все команды» в пульте открывает нижний лист со всей плиткой команд; у опасных команд подпись «С вопросом», при раннем отпускании — «Держите 1 с».

### Иконки старого приложения
- Лента показателей: автозапуск, обороты, напряжение, температуры двигателя/салона/снаружи, топливо, GSM 0–3/выкл, GPS.
- Команды: охрана/снятие, запуск/продление/остановка двигателя, багажник, подогреватель, сброс ошибок, режим ТО вкл/выкл, режим программирования вкл/выкл, паника, световой путь. Цвет — primary, опасные — error.

### Главный статус
- Снято с охраны / На охране / Активная охрана / Тревога. При тревоге карточка мигает, вокруг экрана пульсирует красная рамка, в подзаголовке — зоны в тревоге.
- Компактная карточка: иконка 44 + заголовок + последнее событие в одну строку. Строки «На связи» нет — на связи говорит зелёная точка на иконке, мигающая на каждом обновлении; при потере данных иконка меняется на «нет синхронизации», а вместо события — «Нет данных N с». Отступ до вкладок уменьшен.
- Статус вспыхивает при смене охраны.
- Загрузка — скелетон и «Ждём первый ответ блока…», без нулей. Данные устарели — «Нет новых данных N с» + плашка.
- Режим ТО / программирования — постоянная плашка «Блок не охраняет» с кнопкой «Выключить».

### Зоны (2 варианта для сравнения)
- **A · список:** группы «Двери и кузов», «Органы управления», «Датчики»; строка: значок, подпись, значение-плашка; итог группы справа («Всё закрыто» / «Открыто: N»).
- **B · схема:** силуэт автомобиля из присланных слоёв (`features/check-state/vehicle/`, перекрашены токенами: покой — on-surface-variant, активно — primary, тревога — error, ТО/программирование — tertiary) + подписанные плашки капота, дверей и багажника вокруг; на силуэте также охрана, зажигание, тормоз, паркинг, габариты, датчики, автозапуск (2 кадра), подогреватель. Органы управления и датчики дублируются плитками с подписями.
- Изменение с прошлого обновления: вспышка + обводка + метка «Изменилось» до следующего обновления.
- Названия приведены к одному стилю: «Передняя левая дверь», «Педаль тормоза», «Температура в салоне» и т.д.

### Двигатель, питание, связь, дополнительно
- Двигатель (Заглушен / Запущен / Готов (Ready)), автозапуск с крупным отсчётом `мм:сс` и полосой; обороты только при работе.
- Показатели — плитки; отсутствующие скрываются. Связь — GSM (полоски), GPS, SMS и звонки.
- «Дополнительно» — раскрывающиеся группы: CAN (пробег, запас хода, расход, омыватель, окна, шины), электромобиль, подогреватель, камера, сирена и hands-free, моточасы.

### Команды
- Кнопка с подписью и значком; удержание 1 с с заполняющейся полосой, «Держите…»; отпустил раньше — «Удерживайте 1 секунду».
- Состояния: доступна → отправляется (повтор недоступен) → «Выполнено» / «Блок не ответил» / «Нет связи с блоком»; плюс снэкбар с «Повторить».
- Запуск двигателя и паника — лист подтверждения: пояснение, для запуска живые проверки (нейтраль/«P», ручник, капот), удержание 2 с.
- Режим программирования — только в расширенном монтаже, включение через диалог PIN.

### Выход и быстрый монтаж
- Выход при включённом ТО/программировании: «Выключить и выйти» / «Оставить включённым» / «Отмена».
- Чек-лист: «Пройдено N из M» + полоса; авто-задание показывает текущее значение зоны и отмечается само (тост «Проверка пройдена»), можно «Пропустить»; ручное — кнопки «Да / Нет».
- «Далее» с счётчиком; при незакрытых заданиях — «Не все проверки пройдены. Завершить?». «Назад» — с подтверждением. Без заданий — нет вкладки «Проверки».
- Блок в режиме программирования — плашка «Необходимо выйти из режима программирования. Перезагрузка системы», выход автоматически.

### Плитка T1
- «Проверка состояния» / «Датчики, двери, команды — в реальном времени», duotone-иконка «спидометр»; только для BLE-профиля, ведёт на экран.

## Решения по вопросам ТЗ
1. Силуэт из слоёв используется только в варианте B и всегда с подписями; вариант A — без силуэта.
2. Нормальное состояние датчика удара / доп. датчика подписано «Норма» (в ТЗ — «выключен»).
3. Защита — удержание с явной полосой; для опасных — дополнительный лист подтверждения.

## Заметки
- Не использованы присланные иконки без данных/команд в ТЗ: SIM, баланс, трекинг, временной канал, звонки, сиденье, руль, окна, бипер; слои сирены и hands-free на силуэте.
- Тексты диалогов «Назад» в быстром монтаже и пункты листа запуска — предложение, сверить.
- Варианты зон A/B — выбрать один.
