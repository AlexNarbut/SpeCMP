## Что изменилось
- Один экран для точек входа A–E: режим просмотра / выбора, каталог «все» / «с конфигурациями». Заголовок зависит от режима.
- Поиск сверху на всех уровнях, подсветка совпадения, запрос «марка модель», переход к CAN-поиску из пустого результата.
- CAN-поиск: 4 ячейки, автопоиск, исходы 0 / 1 / много; в режиме выбора — «Выбрать» прямо в результатах. В точке B поле заполнено кодом прошивки блока.
- Крошки, «Недавние» (до 5), автопропуск единственной комплектации.
- Строки в режиме выбора: кнопка «Выбрать» под текстом, чтобы названия не переносились.
- Compact — по шагам; Medium — 2 колонки + карточка на весь экран; Expanded — колонки + карточка справа (3-я колонка комплектаций от 1400 dp).
- Карточка: компактная шапка (фото 4:3 сбоку; на телефоне — полоса CAN-кода и бейджи строками во всю ширину, на широком окне — три плитки CAN · Блокировка · Обход), бейджи возможностей с примечанием по тапу, блок «Важно» («Показать полностью» — только если текст длинный или примечаний два), только непустые вкладки, матрица функций «Чтение · Управление», галерея (свайп, «3 из 7», миниатюры, полноэкранный просмотр с зумом).
- Состояния каждого уровня: загрузка (скелетон), ошибка с «Повторить» без потери выбора, нет интернета, пусто, фильтр отсеял всё (+ «Сбросить фильтр»), фото не загрузилось, карточка без вкладок, длинные названия.
- Новые компоненты кита: BusChip, CapBadge, Ph, VsRow, StateBox, CanInput, SearchBar, Crumbs, Gallery, PhotoViewer.
- Шины (дополнение 5.1): все 16 значений `CarBusGroup` + «Неизвестно»; цвет — по семейству, номер — текстом; длинные подписи («IMO-KEY1 + IMO-KEY2», «CAN-FD1 (CAN-FD3)») переносятся целым чипом; неизвестный код сервера → «Неизвестно». Группы по коду сервера (неизвестный → «Основные»), сортировка по `order`. На телефоне «Чтение» / «Управление» строками под названием, без горизонтальной прокрутки.

## Зачем
В старом приложении не было поиска, три колонки не помещались на телефоне, ошибки — без «Повторить», из поиска по CAN нельзя было выбрать автомобиль, примечания открывались отдельными попапами.

## Решения по вопросам ТЗ (п.10)
- «Недавние» — да, до 5, локально.
- Medium — две колонки (марки · модели) + карточка на весь экран.
- Переход в «Архив прошивок» с CAN-кодом — да, в режиме просмотра (кнопка под CAN-кодом).

## Заметки
- Утверждены: марки списком, шапка карточки B, матрица B. Альтернативы (плитки марок, шапка A, матрица A) остались в коде без переключателей.
- Тексты шапки проверены на узком Android-окне: переносы, крупный системный шрифт.
- Диалог несовпадения CAN-кода (точка C) — черновой текст, финальный — по device-settings-design-brief.
- Данные, логотипы и фото — демонстрационные заглушки.
