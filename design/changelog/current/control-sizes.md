# Размеры контролов — выравнивание с приложением

**Экраны:** все, где есть кнопки L/XL и поля ввода (авторизация, быстрый монтаж, настройки и др.).
**Файлы:**
- design-system/tokens/spacing.css — заменён файлом из uploads/design-sizes-handoff-2026-11-19/
- design-system/guidelines/spacing-sizes.html — подписи и образцы высот

## Что изменилось
- `--h-button-l` 56 → 52, `--h-button-xl` 64 → 56, `--h-input` 72 → 56.
- Новые токены: `--h-code-cell` 72 (ячейка ввода кода), `--h-tag` 32 (`CmpTag`).
- Страница размеров: подписи L 52, XL 56, Input 56; добавлены образцы Code cell 72 и Tag 32.

## Зачем
В приложении (develop) высоты уже уменьшены; старые значения в макетах откатывали код при выгрузке.

## Заметки
- `CmpButton`, `CmpTextField`, `CmpDropdown` берут высоты из токенов — правки в компонентах не нужны.
- В следующих выгрузках `spacing.css` должен приходить уже с этими значениями.
