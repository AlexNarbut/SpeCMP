# 2026-11-13 — Информация о товаре

**Экраны:** product-info (телефон, планшет, Desktop, холст состояний); assistant, assistant-wide; home; advanced-mount
**Файлы:**
- features/product-info/ — ProductInfo.jsx, ProductInfo.dc.html, ProductInfoWide.dc.html, ProductInfoStates.dc.html, README.md
- features/assistant/Assistant.jsx — действие `product` в теме «Устройства», поиск по номеру, полный экран поверх ассистента, переключатель витрины «Товар: найден / не найден / обрыв сети»
- features/assistant/AssistantKit.jsx — карточка журнала `product` (ProductBody), нейтральная ошибка сети в CardShell (`errTone: "net"`)
- features/assistant/Assistant.dc.html, AssistantWide.dc.html — подключён ProductInfo.jsx
- features/home/HomeScreens.jsx, Home.jsx — описание и иконка карточки, переход
- features/advanced-mount/AdvancedMount.jsx — вход перенесён в шапку блока
- res/nav.js — ключи `product-info*`, `window.psProduct(from, n)`

## Что изменилось
- Новый экран «Информация о товаре»: поле «ID устройства или цифры штрих-кода» (цифровая клавиатура, очистка, «Найти»), ошибки ввода под полем, начальное состояние с подсказкой, где взять номер, загрузка скелетоном, «не найден» в нейтральном тоне, нет сети и ошибка сервера с «Повторить».
- Карточки «Товар» (название, ID, серийный номер, заводская дата, прошивки) и «Комплект» (название, серийный номер, дата упаковки); компоненты на телефоне — строки с раскрытием, на широком окне — таблица. Копирование ID и серийников иконкой + снекбар. Пометка «Подключённый блок».
- Сканер штрих-кода: кнопка в поле, окно камеры с рамкой, лазерной линией, фонариком; распознано → номер в поле и поиск; подсказка при долгом распознавании; нет доступа к камере. На Desktop кнопки нет.
- Ассистент: действие «Информация о товаре» в теме «Устройства» (без сети заблокировано), карточка в журнале (загрузка / итог / не найден / нет сети), «Подробнее» → полный экран; число из 6+ цифр в поиске → «Информация о товаре №…» первой строкой; поиск по словам «товар», «комплект», «серийный», «штрих-код», «упаковка».
- Главный: описание «Найти информацию о товаре и комплектации», иконка `manage_search`, переход на экран.
- Расширенный монтаж: «Информация о товаре» из-под шапки перенесена в шапку блока рядом с именем; ведёт на экран с номером блока.

## Зачем
ТЗ `uploads/product-info-design-brief.md`: проверить товар и комплектность по номеру с коробки или блока; при монтаже — данные подключённого блока одним нажатием. Сканер — по запросу в чате.

## Окна и темы
Compact 412×840; планшет 800×1280 / 1280×800; Desktop 1280×800 / 800×600; светлая и тёмная.

## Заметки
- Compact: «Найти» без иконки и шрифт поля 18, чтобы 13 цифр штрих-кода помещались целиком.
- Холст всех состояний — `features/product-info/ProductInfoStates.dc.html`; переходы между макетами — `window.psProduct(from, n)`.
- `product_search` нет в Material Icons Filled — в макете `manage_search`, в коде остаётся своя иконка.
- Экран доступен, только если сервер включил функцию пользователю; без доступа входов нет (в макете не показано).
- Слияние не выполнялось — черновик в `changelog/product-info/`.

### Правки по ревью (2026-11-13)
- Сканер: новое состояние «Камера недоступна» (камеры нет, занята, не запускается): `videocam_off`, только «Ввести вручную». Телефон и планшет, светлая и тёмная — в холсте состояний.
- Сканер: «Нет доступа» разделено на «отказали один раз» («Разрешить доступ» — повтор системного запроса) и «отказали навсегда» («Открыть настройки»).
- Порог «Слишком длинный номер» — больше 19 цифр (было 20), в README и в логике макета.
- Компоненты на телефоне — только строки с раскрытием; вариант «карточки» удалён из кода, витрины и README.
- «Подключённый блок» сравнивает ID найденного товара с ID блока (не текст поля): нашли другой товар — пропадает, снова нашли блок (в т.ч. по штрих-коду коробки) — возвращается. В холсте — группа кадров, в витрине — переключатель «Номер блока / Другой номер».
- Ассистент → «Подробнее» показывает пометку — кадр в холсте состояний.
- Код без номера (QR со ссылкой) — пропускаем молча, через 8 с обычная подсказка; отдельной плашки нет (зафиксировано в README).
- Плашка «Распознано» показывает номер с группировкой EAN-13.
- Иконка на главном: в приложении остаётся `product_search`, `manage_search` — только заглушка макета (README).
- Ждут фото коробки и наклейки: текст под рамкой, формат цифр, пропорции рамки.
