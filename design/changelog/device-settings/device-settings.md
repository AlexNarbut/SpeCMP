# 2026-10-22 — Настройки устройства (расширенные настройки)

**Экраны:** device-settings (редактор настроек, окна редактирования, состояния S1–S11, меню «⋯», поиск)
**Файлы:**
- features/device-settings/DeviceSettings.jsx, ds-demo.jsx, DeviceSettings.html, DeviceSettingsTablet.html, DeviceSettingsDesktop.html, DeviceSettingsParts.html, README.md
- res/nav.js (ссылки `device-settings`, `device-settings-tablet`, `device-settings-desktop`, `device-settings-parts`)

## Что изменилось
- **Раскладка.** Compact (<600): переход по разделам, хлебные крошки, редактор — нижняя шторка. Medium (600–839): дерево 232 + раздел, редактор — диалог. Expanded (≥840): дерево 280 + раздел (max 720), диалог. Шапка Compact — две строки: «Настройки» с кнопками назад / поиск / меню, ниже модель, номер и бейдж «Единая CAN».
- **Строки 13 типов:** раздел, переключатель, выбор, целое, дробное, текст, время, расписание, сирена, CAN-код, вход, выход, переключаемый выход. Состояния: обычное, изменено (подсветка + точка), недоступно, длинное название (2 строки), фокус. Сегменты прямо в строке для выбора ≤3 вариантов по ≤6 символов.
- **Иконка подсказки** ⓘ — постоянная, слева у номера настройки (48 dp); без описания — неактивна, колонка не прыгает.
- **Длинные значения.** Текст > 12 символов и выбор > 16 символов выводятся целиком под названием с переносом; короткие — справа.
- **Входы/выходы.** Заголовок: номер → название канала (CH1, SIREN) → полярность (+/−, НО/НЗ) → бейдж «Изменено»; справа кнопка смены полярности одним нажатием (без окна), для неизменяемой — замок. Под заголовком метка провода (1–3 цвета, «Жёлто-чёрный, Pin 5», перенос) и строка назначенных функций через запятую («Не назначено» если пусто). Разделители групп «Основные / Дополнительные выходы» (R1, R2 без провода).
- **Окна редактирования.** Число/дробное (− / +, автоповтор, ползунок, ввод с клавиатуры), выбор (длинный список с переносом названий, прокрутка к текущему), текст (счётчик, проверка), время, расписание, сирена, CAN-код (поиск автомобиля). Метка «Было: …» занимает место сразу — содержимое не прыгает.
- **Окно входа/выхода.** Компактная шапка «CH1 (+)» с переключателем полярности / типа контакта справа, строка проводов и «Было». Основное — список функций (до 80) с галочками, закреплённая строка «Выбрано N из M» + «Выбранные» + поиск. Подпись про неизменяемость пинов убрана.
- **Запись.** Панель «Изменено: N · Записать», диалоги S4–S11 (прогресс записи, успех, ошибка с «Повторить», выход с несохранёнными, сброс, обрыв связи, режим загрузки базы CAN, пустой раздел), чтение/ошибка чтения, поиск (идёт / пусто), меню «⋯» (сброс; конфигурации — отключены, 2-й этап).
- **Новые компоненты:** Segmented, StepBtn (с автоповтором), WireTag (1–3 цвета), Pol, CountPill, Breadcrumbs, Tree.
- Страница `DeviceSettingsParts.html` — все типы строк × состояния и новые компоненты.

## Зачем
Старое приложение показывало настройки списком без отметок изменений, длинные значения обрезались, функции входов/выходов были единым нечитаемым текстом, а смена полярности требовала отдельного окна.

## Решения по вопросам ТЗ (п.10)
- При обрыве связи правки сохраняются и предлагаются к записи после переподключения.
- Сегменты в строке — ≤3 варианта по ≤6 символов.
- Один уровень дерева на desktop; «служебные» настройки визуально не выделяются (кроме неактивных).

## Заметки
- Не сделаны: конфигурации C1–C7 (пункты меню отключены).
- Плитка «Расширенные настройки» в «Расширенном монтаже» пока не ведёт на новый экран.
- Данные (дерево, функции, провода, автомобили) — демонстрационные.
