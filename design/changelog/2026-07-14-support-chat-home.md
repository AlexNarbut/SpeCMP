## Что изменилось
- Новая фича `features/support-chat/`: экран переписки со специалистами техподдержки.
- Сообщения: текст, документы (плитка с именем/размером), фото (плейсхолдер + подпись).
- Входящие подписаны email отвечающего специалиста (специалисты меняются);
  индикатор «<email> · печатает…» с анимированными точками.
- Статусы исходящих: ✓ отправлено / ✓✓ прочитано / ⏱ в очереди (офлайн).
- Разделители истории по датам («12 июля», «Сегодня»).
- Ненавязчивые «обои» ленты: почти прозрачные мелкие гаечные ключи (силуэт в стиле
  референса заказчика: круглая голова с открытым зевом + рукоятка), хаотично разбросанные
  под разными углами (SVG-тайл как CSS-маска, тонировка on-surface/primary через
  color-mix) + мягкое primary-свечение сверху; адаптивно к темам.
- Пустое состояние: «призрачный» мини-диалог из dashed-пузырей с плавающей иконкой
  поддержки + чипы-подсказки «Документы» / «Фото монтажа».
- Состояния экрана: диалог, пустой чат, загрузка истории (скелетон), офлайн
  (баннер + очередь отправки + «Повторить»).
- Композер: отдельные кнопки «документ» и «фото», чипы вложений к отправке,
  автоувеличение поля ввода, кнопка отправки 48dp; на desktop Enter = отправить.
- Топбар: заголовок слева на mobile/планшете, по центру на desktop.
- 2 варианта пузырей: с фоном (tonal) / плоские (flat) — тумблер в хостах.
- Хосты mobile 412×840 / планшет 800×1280 и 1280×800 / desktop 1100×760 и 1280×800.
- `res/nav.js`: ключи `support-chat`, `support-chat-tablet`, `support-chat-desktop`.
- Главный экран: в чат ведёт карточка «Заявки» (пункт меню «Заявки на техпомощь»
  добавляли, позже убрали по решению заказчика — вход только через карточку).

## Зачем
Задача: экран чата техподдержки — переписка, отправка документов и изображений,
видимость «кто печатает» (идентификация по email). Ответы заказчика: вход из меню
главного, отдельные кнопки фото/файл, статусы «отправлено/прочитано», все 4 состояния,
все три окна, 2 варианта пузырей, разделители по датам.

## Заметки
- Пикеры файлов/фото — моки (циклятся демо-имена); реальное приложение открывает
  системные пикеры и рендерит фото.
- Вариант пузырей — только тумблер хостов; в приложении будет выбран один.
- С планшетного «Главного» переход ведёт на mobile-версию чата (HomeApp не знает
  платформу tablet) — при необходимости уточним.
