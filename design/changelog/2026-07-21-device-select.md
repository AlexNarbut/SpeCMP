# 2026-07-21 — Экран поиска / выбора устройства

**Экраны:** device-select
**Файлы:** features/device-select/DeviceSelect.jsx, features/device-select/DeviceSelect.html,
features/device-select/DeviceSelectTablet.html, features/device-select/DeviceSelectDesktop.html,
features/device-select/DeviceSelectStates.html, features/device-select/README.md, res/nav.js,
features/home/Home.jsx

## Что изменилось
- Новая фича `device-select` — поиск и выбор устройства перед монтажом. Точка входа: карточки
  «Быстрый монтаж» / «Расширенный монтаж» на главном (одинаковый экран для обоих).
- Полный поток с состояниями: запрос разрешений (Android — BLE+USB, iOS — только BLE, Desktop —
  без запроса), доступ отклонён (+как починить), Bluetooth выключен, поиск (радар), список
  найденных, пусто, подключение (заглушка).
- Список — единый плоский, у каждого устройства иконка транспорта. Строка: плейсхолдер-слот фото
  (пользователь заменит) + иконка типа, имя, чип Bluetooth/USB, адрес моноширинно, RSSI-столбики
  для BLE. Устройства — только BLE и USB-HID.
- Адаптив по Window Size Classes: compact — столбец; stacked (планшет-портрет) — центр. столбец;
  split (Expanded/ландшафт/Desktop) — master-detail со списком слева и карточкой+«Подключить» справа.
- Три опорных хоста (mobile 412×840 с тумблером Android/iOS, tablet 800×1280 / 1280×800,
  desktop 1280×800), у каждого — переключатель состояний и тем. Обе темы.
- Обзорный лист `DeviceSelectStates.html`: каждое состояние сразу в трёх размерах (Mobile ·
  Планшет-ландшафт · Десктоп) в одном документе; для permission/denied/adapterOff колонка Desktop —
  «не применимо».
- `res/nav.js`: добавлены ключи device-select / -tablet / -desktop / -states. `Home.jsx`: onNav
  quick/extended → device-select[-desktop].
- `thumbnail.html` дизайн-системы: имя на primary + полоса акцентов (плитка на главной).

## Зачем
После выбора сценария монтажа монтажнику нужно подключиться к блоку сигнализации. Разрешения
и доступные транспорты различаются по платформам, поэтому экран платформо-зависимый.

## Заметки
- По ТЗ пользователя: без кнопки «Искать снова» и без ручного ввода адреса — поиск идёт
  автоматически и продолжается фоном (индикатор «поиск…» в списке и в пустом состоянии).
- «Подключение…» — заглушка; следующий экран (сам монтаж) вне рамок этой задачи.
- Фото устройств — полосатые плейсхолдер-слоты; заменить реальными снимками моделей Pandora.
