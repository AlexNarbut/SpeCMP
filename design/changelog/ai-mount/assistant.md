# 2026-11-11 — Ассистент монтажа «Пульт» (v1, без ИИ)

**Экраны:** assistant (телефон), assistant-wide (планшет / Desktop); advanced-mount (плитка «Ассистент»)
**Файлы:**
- features/assistant/Assistant.jsx — экран «Пульт» и демо; AssistantKit.jsx — общие блоки ленты (`window.AsstKit`); Assistant.dc.html, AssistantWide.dc.html, README.md
- features/advanced-mount/AdvancedMount.jsx — раздел `assistant` первым во всех профилях, плитка на всю ширину сетки, переход в ассистент, экспорт `AM_Loaded`
- res/nav.js — ключи `assistant`, `assistant-wide`
- удалены: первая версия ленты с чипами под карточками (варианты A/B, «лента + панель / по центру»), холст компонентов AssistantParts, промежуточные AssistantV2*

## Что изменилось
- Плитка «Ассистент» в сетке расширенного монтажа: первая, на всю ширину, primary-container + контур primary, метка «Новое»; для блока не из базы — подпись о меньшем наборе действий. Duotone-иконка раздела (квадрат + молния).
- Концепция «Пульт». Лента — журнал: шаги монтажника узлами на рейке («Прошивка › Проверить прошивку · 9:31»), под ними карточки. Кнопок следующих шагов в ленте нет, только действия над самой карточкой (правка, запись, повтор).
- Пульт под лентой (Compact/Medium), слева постоянно на Expanded ≥ 840 dp: плитка «Следующий шаг» по маршруту CAN → прошивка → обход → Clone → состояние; темы с живым статусом (Прошивка, Обход и Clone, Настройки, Состояние, Автомобиль, Поддержка); подуровень темы с действиями «Ответ в ленте» / «Откроет экран»; после результата пульт сам открывает тему результата.
- Поиск в пульте по основам слов показывает разделы, действия и настройки сразу при вводе («бесключевой обход» / «обход» / «clone» → тема «Обход и Clone», «Обучить обход», «Запустить Clone», настройки обхода); стрелка — все совпадения в ленту.
- Прокрутка ленты вверх сворачивает пульт до быстрых действий: Состояние, Загрузить настройки, Все настройки.
- Карточки результата: прошивка (Основной блок / Bluetooth / CAN), состояние, статус обхода и Clone, найденные настройки, ничего не найдено; загрузка / данные / ошибка с «Повторить». Правка настройки в ленте (переключатель, список, число), выбор источника настроек карточкой.
- Возврат с другого экрана: «Перечитываем блок» → итог со сравнением «до → после» (успех / ошибка / прервано / блок не изменился).
- Прошивка: экран загрузчика поверх всего графа, возврат с той же лентой; вариант «связь пропала в загрузчике».
- Подтверждение записи «было → станет»: ожидание, «Нужен PIN» + существующий диалог PIN, запись, записано, ошибка, отменено; предупреждение о несохранённых правках в редакторе («Записать только эту» / «Открыть редактор»).
- Состояния: заводской CAN (плашка в шапке, следующий шаг «Обновить CAN»), USB (без «Состояния», приветствие поясняет), нет сети, модели нет в базе, потеря связи, ошибка с первой попытки, открытая клавиатура. Шапка блока сворачивается в строку после первого действия, при прокрутке и клавиатуре.

### Правки по ревью (2026-11-11)
- Expanded: строка поиска перенесена под ленту (справа внизу), как в привычной схеме «лента + поле ввода».
- Expanded: пульт слева всегда показывает следующий шаг и темы и не меняется при вводе. Найденное появляется справа — панелью над строкой поиска (до 78% высоты, лента видна выше, закрытие крестиком).
- Результаты поиска — строки, а не плитки: группы «Разделы / Действия / Настройки», название целиком, путь или статус второй строкой, значение настройки справа, совпадение подсвечено; две колонки, если хватает ширины.
- Если у раздела одно действие (Автомобиль, Поддержка), в результатах показывается только раздел, без дубля.
- Выбор раздела из результатов открывает его подуровень в пульте и закрывает панель результатов.
- Compact/Medium без изменений: результаты в нижнем пульте горизонтальными плитками.

## Зачем
ТЗ `uploads/ai-mount-design-brief.md` и концепт `uploads/ai-mount-concept.html`: одна точка входа в функции расширенного монтажа; одно нажатие запускает функцию или показывает ответ; ассистент подсказывает следующий шаг монтажа.

## Окна и темы
- Compact 412×840 (Assistant.dc.html); планшет 1280×800 / 800×1280, Desktop 1280×800 / 800×600 (AssistantWide.dc.html); светлая и тёмная.
- Medium — пульт внизу, лента по центру (max-width 840); Expanded — пульт слева 400 dp, лента до 760 dp, поле поиска под лентой; пульт слева всегда с действиями; найденное при вводе — справа, панелью над строкой поиска, списком строк по группам «Разделы / Действия / Настройки» (название целиком, значение справа, совпадение подсвечено).

## Заметки
- Экраны прошивки, обхода, Clone, настроек, конфигуратора, диалог PIN и «Потеря связи» не перерисовывались — заглушки с выбором итога возврата.
- Тексты демонстрационные. Свободные вопросы (LLM) и «Быстрый монтаж» — следующие этапы, в макет не входят.
- Новые компоненты для кита: CmpFeedStep (узел журнала), CmpActionTile (плитка пульта: hero / topic / action / setting, состояния blocked и pulse), CmpActionDock (пульт: уровни, свёрнутый режим), CmpResultCard, CmpConfirmWriteCard, CmpReturnCard (с «до → после»), CmpSkeleton, CmpDeviceHeader, CmpNumberStepper.
- Слияние не выполнялось — черновик в `changelog/ai-mount/`.
