# Оформление — пользовательские темы

**Экраны:** appearance (телефон, планшет, Desktop; светлая и тёмная)
**Файлы:**
- features/appearance/ — Appearance.dc.html, README.md

## Что изменилось
- Новый экран «Оформление»: готовые темы (Pandora, Графит, Контраст, Мастерская, Ночная смена), каждая — пара светлая + тёмная.
- Цвета настраиваются отдельно для светлой и тёмной темы: 4 основных (акцент, фон, карточки, текст) + 7 в «Все параметры» (текст на акценте, вторичный текст, обводки, 4 статуса). Редактор цвета: HEX, системная палитра, пипетка (где доступна), образцы.
- Размер текста 100 / 115 / 130 / 150 %, скругления (общий ползунок + по элементам), заливка кнопок (заливка / тональная / контурная), форма (острые углы / скруглённая / пилюля).
- Фон экрана: заливка или градиент (второй цвет + направление: сверху вниз / по диагонали / из угла), отдельно для светлой и тёмной темы. Контраст текста и акцента проверяется на обоих концах градиента.
- Отступы кнопок и чипов: маленькие / средние / большие; скругление чипов — отдельный ползунок в основном блоке.
- Переключатель «Одинаково для обеих тем» для размеров, формы и кнопок; выключен — настраиваются по теме.
- Живой предпросмотр с переключением светлая/тёмная; черновик → «Применить» / «Отменить».
- Экспорт и импорт темы файлом `.json` (`format: pandora-spec-theme`). Тема хранится только на устройстве.

## Зачем
Запрос: пользователи сами настраивают внешний вид приложения для светлой и тёмной темы.

## Окна и темы
Compact 412×915; планшет 800×1280; Desktop 1280×800; светлая и тёмная.

## Заметки
- Жёсткие ограничения: текст 4.5:1, акцент/обводки/статусы 3:1 (контурная кнопка — 4.5:1). Цвет, не прошедший проверку, сохранить нельзя; предлагается ближайший подходящий. Контурная заливка блокируется, если акцент не проходит 4.5:1.
- Текст меньше 100% и высота элементов ниже 48 dp не настраиваются.
- Импорт: цвета с плохим контрастом исправляются автоматически, количество показывается в снекбаре.
- Экран-обёртка в макете не перекрашивается применённой темой — тема видна в предпросмотре.
