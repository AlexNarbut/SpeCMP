## Что изменилось

### Каркас мастера
- Телефон (<760): topbar с названием шага и «Модель · ID блока», закреплённая панель с главной кнопкой; шагов и номера шага нет.
- Широкое окно (≥760): вариант B — колонка шагов слева, справа topbar + контент + панель. Подготовка — одна точка с подшагами.
- Статусы шага: пройден, текущий, впереди, по необходимости (Clone пунктиром), пропущен, следующий после перезагрузки.
- Перезагрузка — состояние перехода: бегущая линия с таймером в колонке и экран «Перезагрузка блока…» (60 с → «Потеря связи»).
- Clone плавно разворачивается в обычный шаг, когда обход его потребовал. По USB нет Slave и проверки системы.
- Тап по шагу — короткая справка, перехода нет.
- «Назад» — по таблице ТЗ: замок, три диалога, на «Готово» нет.
- Ожидание ответа — кнопка со спиннером; ошибка шага — плашка с причиной и «Повторить».
- Оверлеи: «Потеря связи», «Подключён другой блок» (сравнение ID, «Отключиться»).

### Экраны
- F1 поиск: несигнализации неактивны, пунктирная рамка, плашка «Только для сигнализаций».
- F2 блок не поддерживает: «Выбрать другой блок» / «Расширенный монтаж».
- F3 проверка блока: актуально / рекомендация обновить / заводской CAN / нет доступа.
- F4 карточка конфигурации: автор, рейтинг, дата, CAN, описание, PDF, фото; несовпадение CAN блокирует «Выбрать».
- F5 сводка: блок, автомобиль, конфигурация, план шагов (Clone пунктиром), предупреждения; USB-пометка.
- F6–F7: «Готовим монтаж…» и ошибка; запись настроек без процентов, ошибка, PIN; тост «Настройки записаны».
- F8 монтаж: PDF скачивается / готово / ошибка; галерея фото и просмотр на весь экран; описание сворачивается. Широкое окно: задача на всю ширину; слева крупное превью карты с кнопкой «Открыть карту» и раскрытое описание, справа фото (первое крупно, остальные сеткой); на планшете-портрете — одна колонка.
- Исправлено: проверка системы на телефоне вылезала за ширину экрана.
- F10 обход/Clone в мастере: итог-успех и «нужен Clone» с «Далее», ошибка без пропуска.
- F11 Slave: плейсхолдер анимации, 3 шага, «Обучение выполнено», подтверждение из старого приложения.
- F12 проверка системы: задания строго по порядку, текущее выделено, остальные «Ожидает».
- F13 отзыв: звёзды + текст обязательны, итоги монтажа, отправка. F14 готово: анимация успеха.

### Доработки по ревью
- Колонка шагов компактнее: без подписи «Готово/Сейчас» (их показывают значок и подложка), счётчик «N из M» рядом с заголовком; в невысоком окне (<860) без карточки авто; при ширине 760–899 — компактная колонка 88 dp (только номера, подсказка по тапу).
- Справка по шагу — всплывающая подсказка рядом с колонкой, а не раскрытие строки.
- Раскладка по ширине контента (а не окна): две колонки только при ширине контента ≥860, иначе одна.
- Slave: «Обучение выполнено» перенесено в нижнюю панель рядом с «Далее» — всегда на виду.
- Карточка конфигурации: на всех размерах одной колонкой (max-width 840): плашка CAN → описание → карта монтажа → фото сеткой.
- Исправлено: в окне 1280×800 контент уезжал вправо за край (ширина широких блоков считалась по содержимому).
- Проверка состояния, широкое окно (check-state): слева статус → пульт (машина развёрнута горизонтально, показатели сеткой справа от неё, активные зоны, строка команд + «Все команды») → «Подробно» одной карточкой с вкладками «Зоны / Двигатель / Связь / Дополнительно»; справа — чек-лист (быстрый монтаж) или все команды (расширенный). «Далее» — в нижней панели справа.

## Зачем
- В старом приложении шаги были отдельными экранами без общего каркаса: не было видно, сколько осталось, «Назад» вёл себя по-разному, ошибки не показывались. Мастер в любой момент отвечает «где я и что дальше».
- Монтажник часто прерывается на работу с машиной — колонка шагов, явная перезагрузка и закреплённая главная кнопка возвращают в контекст за секунду.
- Проверка состояния в широком окне стала компактнее: всё важное (статус, пульт, чек-лист) помещается без прокрутки.

## Заметки
- Доска состояний показывает телефон, широкое окно 1280×800 и минимальное окно Desktop 800×600.
- Шаги обучения Slave и тексты ошибок — предложение, сверить с SDK.
- Иллюстрации перезагрузки, Slave, «Готово», «Не поддерживает» — плейсхолдеры под художника.
- Каталог авто и список конфигураций в прототипе упрощены.
