## Что изменилось

### Каркас
- Оба экрана: старт → процесс → итог. Шапка «Название · Модель · ID», «Назад».
- Compact / Medium / Expanded (max-width 1040, на Expanded — правая колонка на старте), светлая и тёмная темы.
- **Полоса статуса под шапкой** — место зарезервировано на всех фазах: во время процесса плавно появляется (индикатор + фраза + таймер «m:ss»), по завершении плавно гаснет; контент не прыгает. Фразы: «Блок ждёт ваше действие» / «Блок работает. Ожидайте» / «Блок ждёт выполнения инструкции» / «Не прерывайте соединение»; в Clone — «Этап N из 5 · нажимать ничего не нужно».
- **Иллюстрация не прыгает:** один размер контейнера на всех состояниях (высота 160 compact / 210 остальные, пропорция 800:550), всегда первая в контенте.
- Истории шагов, списка этапов Clone и блока «Подсказка» нет — на экране только текущее состояние.

### Бесключевой обход
- **Старт (B1, B1a, X3):** пояснение, «Как это будет», предупреждение о перезапуске по питанию (USB — с текстом про обесточивание), плашка CAN-кода, «Процедура прервана: связь с блоком потеряна» (под иллюстрацией). Кнопки «Перезагрузить систему» нет. PIN по Bluetooth.
- **Шаг — карточка-команда (вариант A):** действие / принято / ожидание различаются цветом карточки, меткой и иллюстрацией (рамка и пульс у запроса, «дыхание» у ожидания).
- **Шаги:** зажигание вкл/выкл, двигатель запуск/остановка, капот открыть/закрыть («Капот открыт/закрыт, ожидайте»), «Вытащите ключ», обмен с ЭБУ, «Идет процесс обучения, ожидайте», «Идет обмен данных с блоком сигнализации. Ожидайте».
- **Критичное ожидание «Не прерывайте соединение»** (LADA CAN, обмен с блоком сигнализации): tertiary-карточка, метка «Критичный обмен данными», крупный запрет.
- **Инструкции (B4):** LADA APS (7 пунктов) и Toyota/Daihatsu TX RX (5 пунктов) переписаны под структуру «действие · Нельзя · Отклик · Если не получилось» (красная плашка); метки «Красный · обучающий» / «Чёрный · рабочий», выделены «4 раза» / «3 раза», последний пункт Toyota — ожидание. Прокрутка вместе с экраном.
- **Итоги:** успех (+ «Перейти к процедуре Clone», если доступно), нужен Clone, не поддерживается, ошибка — «Что случилось» / «Что проверить» + «Повторить» / «В чат поддержки». Примеры ошибок: VIN, CAN2, таймаут, «Повторите обучение», иммобилайзер, общая.

### Процедура Clone
- **Старт:** «Оставшееся число попыток CLONE: N»; 0 попыток — «Исчерпано число попыток CLONE. Обратитесь в тех. поддержку», кнопка недоступна + чат; счётчик неизвестен — старт доступен.
- **Подтверждение** «Начать Clone?» на всех платформах, затем PIN по Bluetooth.
- **Процесс:** 5 этапов, текущий — заголовком, «Этап N из 5» в полосе статуса; этап 3 — «Ваша задача в очереди» / «…обрабатывается». На этапах 4–5 «Назад» заменён замком + плашка «Выход недоступен до конца проверки».
- **Итоги (с иллюстрацией):** выполнено, уже выполнено, не поддерживается, ошибки — «Невозможно вычислить ключ» (+ советы сервера списком), нет доступа, неопознанное устройство, неизвестная, код ошибки; обновлённый счётчик попыток.

### Общее
- Диалог выхода во время процесса — текст брифа: «Внимание» / «…Вы действительно хотите выйти?» — «Да» / «Нет».
- Экран «Потеря связи» поверх → возврат на старт с сообщением X3.
- Обход → Clone; «Назад» из Clone возвращает в обход.

### Иллюстрации
- Подключены присланные SVG (очищены от метаданных, перекрашиваются темой): чёрный → цвет линий, синий `#2672d1` → primary.
- Карта по п.3 брифа; единый масштаб — все в общей рамке артборда 800×550, толщина линий одинаковая.
- Эмблема LADA в `bypass_learning_lada.svg` — без чёрной заливки, контуром (как остальные).
- **Значки статуса унифицированы** во всех иллюстрациях: один вид (контурный круг r44, primary) и одно место (правый нижний угол, 690×440 на артборде) — галочка у «выполнено» (зажигание, двигатель, капот, итог-успех), «стоп» у «Заглушите двигатель», «!» у итога-ошибки. Старые значки (чёрные/синие, в разных местах) удалены; из `turn_on_engine_request` галочка убрана (это запрос). Дорисован разрыв контура ключа в `turn_off_ignition_success`.
- Перерисована: обмен данными (`bypass_engine_exchange_v2`) — контурный двигатель + стрелки.
- Дорисованы: `bypass_toyota_v2` (словесный знак + ключ как в LADA APS), `bypass_key_out` (ключ — как в LADA APS / Toyota), `bypass_engine_stop_request` / `_success`, `bypass_result_success` / `_fail` (итоги обхода и Clone).

## Решения по вопросам ТЗ
1. Кнопки «Перезагрузить систему» нет — только предупреждение.
2. Счётчика и истории шагов нет; у Clone — «Этап N из 5» в полосе статуса.
3. Анимация на ожиданиях есть (пульс/дыхание иллюстрации, индикатор, таймер).
4. Советы сервера — открытый список «Что можно сделать».
5. «В чат поддержки» — без прикреплённого текста ошибки.
6. Отметок подшагов и «Начать инструкцию сначала» нет.
7. Тексты инструкций переписаны под структуру — **нужна сверка с ТП**.
