# Чат техподдержки — фича

Экран **«Техподдержка»** Pandora Spec: переписка монтажника со специалистами техподдержки.
Текстовые сообщения, отправка документов и фото, статусы доставки, индикатор «специалист
печатает…». Специалисты могут меняться — каждое входящее сообщение подписано **email**
отвечающего (`ivan.support@pandora.pro` и т.п.); тот же email показывается в индикаторе набора.

Вход: главный экран → меню → «Заявки на техпомощь» (`onNav("support")` → `psGo`).

## Файлы

- **SupportChatScreens.jsx** — презентационные блоки, только из Cmp*-компонентов ДС:
  `ChatScreen` (топбар + история + композер), `MessageBubble` (text / doc / image),
  `DateDivider`, `MsgStatus`, `TypingIndicator`, `EmptyChat`, `ChatSkeleton`,
  `OfflineBanner`, `Composer`, `PendingAttachment`, хук `useChatMode`.
  Данные: `SC_HISTORY`, `SC_AGENTS`, `SC_REPLIES`, мок-вложения.
- **SupportChat.jsx** — `SupportChatApp`: живой экран. Отправка (✓ отправлено → ✓✓ прочитано),
  симуляция ответа поддержки с «печатает…», мок-пикеры вложений, офлайн-очередь.
- **SupportChat.html** — Compact / телефон (Android-фрейм 412×840).
- **SupportChatTablet.html** — планшет: портрет 800×1280 (Medium) / ландшафт 1280×800 (Expanded).
- **SupportChatDesktop.html** — окно Compose Desktop: Expanded 1100×760 / Large 1280×800;
  Enter отправляет, Shift+Enter — перенос строки.

## Состояния (переключатель в хостах)

- **Диалог** — демо-история с разделителями дат («12 июля», «Сегодня»).
- **Пустой** — сообщений нет; первое отправленное начинает диалог.
- **Загрузка** — скелетон истории + линейный прогресс (~1.8 с), затем диалог.
- **Офлайн** — баннер «Нет соединения» (error-container); отправленные ставятся в очередь
  со статусом ⏱, «Повторить» доставляет их (✓ → ✓✓) и возвращает диалог.

## Варианты пузырей (2 варианта по задаче)

- **С фоном (tonal)** — исходящие `primary-container`, входящие `surface-container-low` + бордер.
- **Плоские (flat)** — прозрачные с контуром; исходящие выделены primary-бордером.

## Вложения

- Документ — плитка 44dp + имя файла + размер/тип; фото — полосатый плейсхолдер
  (реальное приложение рендерит снимок), опциональная подпись.
- В композере отдельные кнопки «документ» (скрепка) и «фото» — по ответам заказчика;
  выбранное показывается чипами над полем ввода, чип можно убрать.

## Адаптив (Window Size Classes по ширине контейнера)

- **compact** (<600) — колонка на всю ширину, пузыри ≤82%.
- **medium** (600–839) — колонка max-width 720, по центру.
- **expanded** (≥840) — колонка max-width 840, по центру.

Зоны касания ≥48dp (кнопки композера, отправка, «Повторить»). Обе темы.

## Навигация

Ключи `res/nav.js`: `support-chat`, `support-chat-tablet`, `support-chat-desktop`.
