# Расширенный монтаж

Экран после выбора устройства: шапка блока (название, ID, тип подключения, режим, версии ПО/CAN, IMEI) + сетка разделов. Состав разделов зависит от типа блока (`PROFILES` в `AdvancedMount.jsx`).

- Профили: сигнализация с CAN, USB-модуль, не поддерживается.
- Состояния: загрузка, ошибка, доступ запрещён, не поддерживается, пусто, потеря связи (BLE/USB), CAN-диалог.
- Плитки, требующие CAN-прошивку, помечены замком и подписью; нажатие открывает диалог.
- Адаптив: Compact — 1 колонка; Medium — 2 колонки; Expanded — панель устройства слева.
- Источник требований: `uploads/advanced-mount-legacy-ui.md`.
