# Ассистент монтажа — «Пульт»

Раздел расширенного монтажа. Требования: `uploads/ai-mount-design-brief.md`, концепт `uploads/ai-mount-concept.html`.

Лента — журнал: шаги монтажника узлами на рейке, под ними карточки результата. Пульт — что делать: внизу (Compact/Medium), слева постоянно (Expanded ≥ 840 dp).

- **Assistant.jsx** — экран `AssistantScreen` и демо-оболочки (`AssistantDemo`, `AssistantWideDemo`).
  Пропсы: `profile` (ble | usb | unsupported), `canFactory`, `online`, `errMode`, `pinRequired`, `unsaved`, `preset` (first | long), `keyboardDemo`.
- **AssistantKit.jsx** — общие блоки (`window.AsstKit`): карточки результата, правка настройки, выбор источника, шапка блока, чипы, заглушки существующих экранов, рамки устройств. Грузится перед Assistant.jsx.
- **Assistant.dc.html** — телефон 412×840 + сценарии.
- **AssistantWide.dc.html** — планшет 1280×800 / 800×1280, Desktop 1280×800 / 800×600, iPhone-ландшафт 852×393 (с safe area).

Низкое окно (высота < 480 dp, ширина ≥ 560 — телефон-ландшафт): пульт слева колонкой (шапка блока свёрнута в строку, темы — строки 64 dp), лента справа, поиск внизу ленты; найденное — панелью поверх ленты.

Пульт: «Следующий шаг» (CAN → прошивка → обход → Clone → состояние) → темы с живым статусом → подуровень темы → действия («Ответ в ленте» / «Откроет экран»). Поиск показывает темы, действия и настройки по основам слов. Прокрутка ленты вверх сворачивает пульт до быстрых действий.

Существующие экраны (прошивка, обход, Clone, настройки, конфигуратор, PIN, потеря связи) не перерисовываются — заглушки с выбором итога возврата.

Темы пульта: Прошивка · Обход и Clone · Настройки · Состояние · **Устройства** (устройства системы, приживление) · Автомобиль · **Поддержка** (заявка на техпомощь — первой, мои заявки, чат). Ошибки обхода/Clone/прошивки/приживления в ленте предлагают «Заявка на техпомощь» и «Чат поддержки».
