# Выбор автомобиля (vehicle-select)

Переиспользуемый экран выбора автомобиля из каталога и карточка автомобиля. ТЗ — `uploads/vehicle-select-design-brief.md`.

## Файлы

- **vs-data.js** — демо-каталог `window.VS_DATA`: марки → модели (годы, группы функций) → комплектации → карточка; индекс по CAN-коду, недавние.
- **VsKit.jsx** — новые компоненты кита (`window.VsKit`): `BusChip`, `CapBadge` (строка / плитка), `Ph` (заглушка фото с фиксированными пропорциями), `Logo`, `Hl` (подсветка совпадения), `VsRow`, `SkelList`, `StateBox`, `Seg`, `CanInput`, `SearchBar`, `Crumbs`, `Html`, `Gallery`, `PhotoViewer`.
- **VehicleCard.jsx** — `VsCard`: шапка (вариант A / B), бейджи, блок «Важно», вкладки, матрица функций (вариант A / B), точки подключения + галерея, схемы, карты монтажа, народные карты.
- **VehicleSelect.jsx** — `VehicleSelectApp` (контейнер, адаптив, поиск, CAN-поиск, фильтр, тип устройства, диалоги) + `useVsCtl` (панель витрины).
- **VehicleSelect.html** — Compact 412×840. **VehicleSelectTablet.html** — 800×1280 / 1280×800. **VehicleSelectDesktop.html** — 1280×800, 800×600, 1600×900.
- **VehicleSelectStates.html** — все состояния раздела 6 в выбранном окне. **VehicleSelectParts.html** — компоненты кита, light и dark рядом.

## Точки входа (переключатель A–E)

| | Режим | Каталог | Особенности |
|---|---|---|---|
| A | Просмотр | Все | Сначала выбор типа устройства; чип «Сигнализация ▾» в шапке |
| B | Просмотр | Все | В подзаголовке — CAN-код прошивки; поле CAN заранее заполнено «код прошивки блока» |
| C | Выбор | Все | Код ≠ коду прошивки блока → диалог предупреждения |
| D | Выбор | Все | Тип устройства; результат — CAN-код в фильтр архива |
| E | Выбор | С конфигурациями | Без фильтра функций и CAN-поиска |

Заголовок: «Выберите автомобиль» (выбор) / «Автомобили» (просмотр). «Выбрать» — закреплена внизу карточки; в списке комплектаций и результатах CAN — кнопка «Выбрать» в строке.

## Адаптив

- **Compact** (<600): шаги Марки → Модели → Комплектации → Карточка, крошки под поиском, «Недавние» над марками.
- **Medium** (600–839): две колонки — марки · модели (комплектации раскрываются под моделью); карточка — на весь экран с крошками.
- **Expanded** (≥840): марки · модели · карточка справа; третья колонка «Комплектации» — при ширине ≥1400, иначе раскрытие в колонке моделей. Недавние — чипами под поиском.
- Выбор хранится в контейнере → поворот / смена ширины не сбрасывают уровень.

## Поиск

- Фильтрует текущий уровень; совпадение подсвечивается.
- «toyota camry» на уровне марок → марка + её модели, отфильтрованные по второму слову.
- Цифры в поле названия → подсказка перейти в режим CAN-кода.
- CAN-код: 4 ячейки, поиск после 4-й цифры. 1 результат → сразу карточка, несколько → список, 0 → «Автомобили с CAN-кодом … не найдены».

## Карточка

- **Утверждено:** марки списком, шапка B, матрица B. Шапка B — фото 4:3 сбоку (120 / 200 px), три плитки: CAN-код с копированием · Блокировка · Обход. (Варианты «плитки марок», шапка A и матрица A остались в коде, переключатели убраны.)
- Бейдж — цвет + иконка + текст; есть примечание → иконка ⓘ, тап открывает шторку (compact) / диалог.
- «Важно» — первые 3 строки, «Показать полностью» раскрывает все примечания на месте.
- Вкладки только непустые. Функции — группы `CarFeatureGroup` (неизвестный код → «Основные»), внутри — по `order`, группы сворачиваются.
  **B (по умолчанию)** — «Чтение» / «Управление» с чипами шин: на телефоне строки под названием функции, на широком — два столбца; чипы переносятся, горизонтальной прокрутки нет.
  **A** — столбец на каждую шину, в ячейке иконки «чтение» / «управление»; при многих шинах — горизонтальная прокрутка с закреплённой первой колонкой.
- Чипы шин (`CarBusGroup`, 16 значений + «Неизвестно»): цвет = семейство (`--bus-can`, `--bus-canfd`, `--bus-lin`, `--bus-bean`, `--bus-imo`), номер — в подписи; «Неизвестно» — пунктирный контур с «?». Подписи не переводятся, кроме «Неизвестно». Новый код сервера → «Неизвестно», функция показывается.
