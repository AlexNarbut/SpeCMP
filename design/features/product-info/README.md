# Информация о товаре

ТЗ: `uploads/product-info-design-brief.md`. Монтажник вводит ID устройства или цифры штрих-кода (или сканирует штрих-код камерой) и видит товар и его комплект.

- **ProductInfo.jsx** — экран `ProductInfoApp` + витрины (`ProductInfoDemo`, `ProductInfoWideDemo`, `ProductInfoStatesDemo`), данные `piLookup`.
  Пропсы: `entry` (home | mount | assistant), `number`, `state0` (empty | loading | content | notfound | offline | server | input — статично, для витрины), `scenario` (nokit | kit2 | kit7 | kit12 | long | sparse), `scanner`, `scan0` (aim | found | hint | denied | blocked | unavailable), `inputErr0` (empty | letters | long), `platform` (mobile | tablet | desktop), `onBack`.
- **ProductInfo.dc.html** — телефон 412×840. **ProductInfoWide.dc.html** — планшет 1280×800 / 800×1280, Desktop 1280×800 / 800×600. **ProductInfoStates.dc.html** — все состояния на одном холсте.
- Навигация: `window.psProduct(from, n)` из `res/nav.js` (ключи `product-info`, `product-info-wide`, `product-info-states`).

## Три входа
1. **Главный** — карточка «Информация о товаре» в инструментах → поле пустое, начальное состояние с подсказкой, где взять номер.
2. **Расширенный монтаж** — кнопка в шапке блока рядом с именем (телефон: «Товар» под иконкой; шире — «Информация о товаре») → номер подключённого блока подставлен, результат грузится сразу, пометка «Подключённый блок».
3. **Ассистент** — действие «Информация о товаре» в теме «Устройства» → карточка в журнале (загрузка / итог / не найден / нет сети + «Повторить»), «Подробнее» — полный экран. Число из 6+ цифр в строке поиска → первая строка «Информация о товаре №…». Действие находится по словам «товар», «комплект», «серийный», «штрих-код», «упаковка».

## Сценарии экрана
- Поиск явный: «Найти» или «Поиск»/Enter на цифровой клавиатуре. Пробелы и дефисы убираются сами. Ошибки под полем: «Введите номер», «Только цифры», «Слишком длинный номер» (больше 19 цифр).
- Сканер: иконка в поле справа (телефон, планшет; на Desktop нет). Окно камеры: рамка под штрих-код, лазерная линия, фонарик, «Ввести вручную». Распознано → цифры под рамкой (группировка EAN-13: 4 607123 456789) → окно закрывается, номер в поле, поиск сам.
  - Код без номера (QR со ссылкой и т. п.) пропускаем молча, сканер работает дальше. Через 8 с без результата — подсказка «Не распознаётся?…». Отдельной плашки нет.
  - Нет доступа, отказали один раз (`denied`) → «Разрешить доступ» повторяет системный запрос. Отказали навсегда (`blocked`) → «Открыть настройки». В обоих — «Ввести вручную».
  - Камера недоступна (`unavailable`: камеры нет, занята другим приложением, не запускается) → иконка `videocam_off`, только «Ввести вручную».
- Результат: «Товар» (название, ID, серийный номер, заводская дата, прошивки «модуль · версия · дата»), «Комплект» (название, серийный номер, дата упаковки, число компонентов) — только если есть, без пустой карточки. Пустые поля не показываются.
- Компоненты на телефоне и планшете-портрете — **строки с раскрытием** (единственный вариант): серийник виден сразу, прошивки и копирование по нажатию, «Раскрыть все». Широкое окно — таблица «Название | Серийный номер | Прошивки».
- «Подключённый блок» (вход из монтажа или ассистента, в том числе «Подробнее» из журнала) сравнивает **ID найденного товара** с ID блока, а не текст поля. Пока на экране результат блока, пометка есть, даже если в поле уже набирают другой номер (карточка ещё про блок). Нашли другой товар — пометки нет. Снова нашли блок (по ID или по штрих-коду его коробки) — пометка вернулась. С главного пометки нет никогда.
- Копирование ID и серийных номеров — иконка у значения, снекбар «Скопировано: …». На Desktop текст выделяется мышью.
- «Не найден» — нейтральный тон. «Нет сети» и «Ошибка сервера» — «Повторить».

## Адаптив
Compact — одна колонка, поле прилипает сверху. Medium (планшет-портрет) — как телефон, max-width 720, отступы 24. Expanded ≥ 840 — поле на всю ширину контента (max-width 1040), «Товар» | «Комплект» в две колонки, компоненты таблицей под ними; без комплекта «Товар» во всю ширину, прошивки справа.

## Иконки
Главный и ассистент — **в приложении остаётся своя `product_search`** (финальная). В шрифте Material Icons Filled её нет, поэтому в макетах стоит заглушка `manage_search` — в код её не переносить. Монтаж — `inventory_2`. Копирование — `content_copy`, сканер — `qr_code_scanner`, фонарик — `flash_on`/`flash_off`, нет доступа — `no_photography`, камера недоступна — `videocam_off`.

## Открыто до фото реальной коробки и наклейки
- Макет исходит из того, что на коробке EAN-13 и его 13 цифр — номер для поиска. Сверить группировку цифр в плашке «Распознано» и пропорции рамки 320×170 (планшет 460×220), если код длиннее или квадратный (QR, DataMatrix).
- Текст под рамкой «Штрих-код — на коробке…» пока без изменений; если на наклейке блока тот же код — «Штрих-код — на коробке или наклейке блока».
