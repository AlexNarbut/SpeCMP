# Проверка состояния

Живое состояние сигнализации и автомобиля + команды на блок. Только Bluetooth (при USB плитки нет, на Desktop экрана нет).

- `CheckState.jsx` — экран `CheckStateScreen` + демо-панель `useCsCtl`. Режимы `advanced` (Расширенный монтаж) и `quick` (шаг Быстрого монтажа с чек-листом).
- `CheckState.html` — телефон 412×840; `CheckStateTablet.html` — 800×1280 / 1280×800 / 915×412; `CheckStateParts.html` — компоненты во всех состояниях.
- Зоны: вариант A — группы строк с подписями; вариант B — схема кузова + плитки. Переключатель в демо-панели.
- Команды — удержание 1 с; запуск двигателя и паника — лист подтверждения с удержанием 2 с.
- Блок присылает данные раз в 3 с — прототип имитирует тик; нажатие на зону в демо = действие в машине.
- Источник требований: `uploads/check-state-design-brief.md`.
- Раскладки v2 (по умолчанию): <600 — вкладки; высота <520 — низкое окно; 600–1099 — две панели по сгибу (`hingeAt`); ≥1100 — три колонки. `layoutV="v1"` — прежние.
- `CheckStateFoldable.html` — раскладной (344×882 / 690×829 / 829×690); `CheckStateLayouts.html` — «сейчас / предложение» рядом.
