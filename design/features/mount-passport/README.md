# Паспорт монтажа

Документ, который монтажник оформляет в конце установки и отдаёт клиенту: автомобиль, оборудование, проверка, исполнитель.
ТЗ: `uploads/mount-passport-design-brief-87e542bb.md`. Главный принцип — монтажник **проверяет и дополняет**, а не заполняет:
путь «Оформить → Сформировать PDF → Поделиться» возможен без единого ввода. Ни одно ручное поле не обязательно,
пустые поля и разделы в документ не попадают.

## Файлы
- `PassportEditor.jsx` — предотчёт. Аккордеон: секции свёрнуты, итог в одну строку; «само» — карточки с пометкой
  источника («Считано с блока», «Из мастера монтажа», «Из профиля»), «дополнить» — поля с подписью «Необязательно».
  Сценарии: `fast` / `ext` / `partial` / `noblock`. `embedded` — без шапки и кнопки (для широкого окна), `onChange` отдаёт данные
  в живой предпросмотр.
- `PassportRead.jsx` — «Считывание блока»: 5 этапов, все состояния п. 3 ТЗ.
- `PassportReady.jsx` — «Паспорт готов» (телефон): листы, «Стр. N из M», формирование / ошибка, действия. `PassportSheet` — лист в масштабе.
- `PassportDoc.jsx` — документ A4: `PassportDocPages({ variant: full | min | noblock | long | live, lang, guides, data })`.
- `PassportList.jsx` — `PassportApp`: список (раздел / архив), экран «Блок» (без блока), навигация и раскладки по классам окна.
- `mp-host.jsx` — демо-панель хостов.
- `MountPassport.html` · `MountPassportTablet.html` · `MountPassportDesktop.html` — телефон / планшет / desktop.
- `PassportDocument.html` — документ A4 (печать — по листу на страницу).
- `PassportEditorOptions.html` — сравнение вариантов предотчёта 2×2 (история выбора; выбран 2a).
- Иконка раздела — `passport` в `res/icons/section-icons.js` (документ + печать с галочкой).

## Входы
1. «Быстрый монтаж завершён» (`features/fast-mount/`, F14 / F14p): блок «Паспорт монтажа» → «Оформить паспорт»; после — «Паспорт оформлен · №» + «Поделиться» / «Открыть». «На главную» остаётся главной.
2. Расширенный монтаж — плитка «Паспорт монтажа» (сигнализация и модуль, BT и USB) → паспорта подключённого блока + «Новый паспорт».
3. Главный экран — плитка «Паспорта монтажа · Найти, открыть и отправить снова» → архив (без блока), «Новый паспорт без блока».
4. Ассистент (`features/assistant/`): плитка пульта «Паспорт монтажа» после «Состояния»; поиск по «паспорт», «акт», «документ», «отчёт»;
   последним шагом маршрута — карточка журнала «Монтаж закончен? Оформите паспорт» → после — «Паспорт оформлен · №» + «Открыть».

## Раскладки (M3 Window Size Classes)
- Compact < 600 — экраны по очереди; кнопка «Сформировать PDF» закреплена внизу.
- Medium 600–839 — то же, колонка по центру (max 720, кнопки max 560).
- Expanded ≥ 840 — архив: список 400 dp + выбранный паспорт листами; редактор: поля слева + живой лист справа,
  действия над листом (desktop: главная «Сохранить файл», «Поделиться» нет). Отдельного «Паспорт готов» нет.
- Низкое окно (высота < 520, телефон-ландшафт) — над листом только главная кнопка и «⋯».

## Документ
A4 книжная, поля 15 мм, ч/б печать: чёрный текст, акцент #2C3639 только в заголовках разделов, тонкие линии, без заливок.
IBM Plex Sans, 3 размера (17 / 9,5 / 7,5 pt). Статусы проверки — значок + слово. Шапка: название, №, дата; справа организация
и адрес (если есть), место под логотип (пустое). Колонтитул: № и «стр. N из M». Подписи не отрываются: последний ряд фото
уходит на страницу с подписями. У устройств — версия ПО.

## Фото
Телефон / планшет: «Добавить фото» → «Снять камерой» / «Выбрать из галереи»; нет доступа к камере → «Открыть настройки».
Desktop: «Добавить файл». Тап по фото — просмотр на весь экран: листание, подпись (одна строка), удаление с подтверждением.

## Без блока
Из архива без подключённого блока правятся только ручные поля («Перечитать» скрыто). Паспорт без блока при подключённом
блоке с тем же ID показывает «Считать блок».

## Перенос (экспорт / импорт)
ZIP: PDF + `passport.json` + `settings.dxs` (по умолчанию вкл.) + `photos/` оригиналы (по умолчанию выкл.). Один паспорт —
«⋯ → Экспорт (ZIP)»; несколько — режим выбора или «Экспорт всех». Импорт — файл → сводка → дубликаты «Пропустить / Заменить».
Код — `PassportTransfer.jsx`.

## Хранение (локально)
Паспорт — папка `passports/<№>/` в личных данных приложения: `passport.json`, `settings.dxs`, `photos/` (копии 2048 px, JPEG 80,
поворот по EXIF применён, геометки удалены), `thumbs/` (320 px), `Паспорт.pdf` (кэш, пересобирается). Список и поиск — индекс SQLite.
Android `filesDir` · iOS Application Support · Desktop: %APPDATA%\PandoraSpec / ~/Library/Application Support/PandoraSpec /
~/.local/share/PandoraSpec. Ссылки на галерею не храним — копируем при добавлении. Удаление паспорта — удаление папки.
≈ 5 МБ на паспорт с 8 фото. Экспорт ZIP = резервная копия; архив раз в месяц напоминает «Сохраните копию архива».

## Решения сверх ТЗ
- Устройства системы читаются и по USB (динамическая таблица) — список без адресов.
- Полный документ — 3 страницы (не 2): иначе подписи остались бы без фото на отдельной странице.
