# Выбор устройства (device-select)

Экран поиска и выбора устройства перед монтажом. Точка входа — карточки **«Быстрый монтаж»**
и **«Расширенный монтаж»** на главном экране (оба ведут сюда, экран одинаковый).

## Файлы

- **DeviceSelect.jsx** — `DeviceSelectScreen` (экспорт в `window.DeviceSelectScreen`): весь поток
  и все состояния, собран только из Cmp*-компонентов ДС. Демо-устройства — в `DEVICES`.
- **DeviceSelect.html** — Compact / телефон (Android-фрейм 412×840). Переключатели: тема,
  платформа (Android/iOS), состояние экрана.
- **DeviceSelectTablet.html** — планшет: портрет 800×1280 (столбец) и ландшафт 1280×800 (master-detail).
- **DeviceSelectDesktop.html** — окно Compose Desktop 1280×800 (без запроса разрешений, master-detail).
- **DeviceSelectStates.html** — обзорный лист: каждое состояние сразу в трёх размерах
  (Mobile · Планшет-ландшафт · Десктоп), тумблер темы. Для permission/denied/adapterOff колонка
  Desktop помечена «не применимо» (на Desktop разрешения не запрашиваются).

## Поток и состояния

```
permission → (Разрешить) → scanning → list | empty
permission → (Не сейчас)  → denied  → (Открыть настройки) → permission
adapterOff → (Включить)   → scanning
list → выбор → connecting            (compact / stacked)
list → выбор → detail → Подключить → connecting  (split / master-detail)
```

- **permission** — запрос доступа. Набор зависит от платформы: **Android** — Bluetooth (BLE) + USB;
  **iOS** — только BLE; **Desktop** — шаг пропускается, сразу `scanning`.
- **denied** — доступ отклонён + подсказки «как починить» (путь в системных настройках).
- **adapterOff** — Bluetooth выключен на устройстве.
- **scanning** — поиск (радар-анимация + спиннер), авто-переход в список через ~2.2 c.
- **list** — найденные устройства единым плоским списком; у каждого иконка транспорта.
- **empty** — ничего не найдено, поиск продолжается (по ТЗ без кнопки повтора/ручного ввода).
- **connecting** — подключение к выбранному устройству (заглушка, следующий экран — позже).

## Строка устройства

Плейсхолдер-слот фото (полосатый, пользователь заменит реальным снимком) + иконка типа · имя ·
чип транспорта (Bluetooth/USB) · адрес моноширинно (MAC для BLE, `HID …` для USB) ·
уровень сигнала RSSI (столбики) для BLE / значок USB. Устройства — только **BLE** и **USB-HID**.

## Адаптив (Window Size Classes по ширине контейнера)

- **compact** (<600) — один столбец, строки на всю ширину; выбор → сразу `connecting`.
- **stacked** (600–839, портрет) — центрированный столбец, `max-width` 620, крупнее.
- **split** (Expanded / ландшафт / Desktop) — master-detail: слева список, справа карточка
  выбранного устройства (крупный слот фото, тип/связь/адрес/сигнал) и кнопка «Подключить».

Зоны касания ≥ 48 dp, обе темы. Разрешение отклонено/пусто и т.п. — центрированные состояния.

## Навигация

Ключи `res/nav.js`: `device-select`, `device-select-tablet`, `device-select-desktop`, `device-select-states`.
Из главного: `onNav("quick"|"extended")` → `device-select[-desktop]`. Назад → `home`.
