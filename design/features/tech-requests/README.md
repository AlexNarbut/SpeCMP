# Заявки на техпомощь — фича

Раздел расширенного монтажа **«Заявки на техпомощь»**: монтажник заказывает обратный звонок специалиста
и следит за своими заявками. Это **не чат**: к заявке автоматически прикладываются модель блока, прошивка,
все настройки и язык приложения (координаты тоже уходят, но в интерфейсе не упоминаются). Источник — `uploads/tech-requests-design-brief.md`.

Вход: расширенный монтаж → плитка `tickets` → `psGo("tech-requests")` (compact) / `"tech-requests-tablet"`.

## Файлы

- **TechRequests.jsx** — `TechRequestsApp` (экран целиком) + блоки: `TrCard`, `TrStatusChip`, `TrChips`,
  `TrForm`, `TrProblemField`, `TrAttachBlock`, `TrSending`, `TrSuccess`, `TrEmpty`, `TrError`. Тексты RU/EN — `TR_I18N`.
- **tr-host.jsx** — демо-панель хостов (тема, язык, группировка, раскладка, сценарий, ответ сервера).
- **TechRequests.html** — телефон (Compact, Android-фрейм).
- **TechRequestsTablet.html** — планшет: портрет 800×1280 (Medium) / ландшафт 1280×800 (Expanded).
- **TechRequestsDesktop.html** — окно 800×600 / 1100×760 / 1280×800.
- **TechRequestsStates.html** — доска статичных кадров всех состояний (телефон светлая/тёмная, широкое окно).

## Сценарии

1. **Новая заявка (телефон).** FAB «Новая заявка» → полноэкранная форма. Имя и телефон из профиля, фокус в
   «Опишите проблему». «Отправить заявку» закреплена внизу.
2. **Новая заявка (широкое окно).** Desktop — всегда «Список + панель» (от 800, панель 380–480). Планшет: вариант «Список + панель» (≥840): форма всегда открыта справа (440–480),
   «Новая заявка» в пустом состоянии ставит фокус в поле. Вариант «Список + диалог»: список max-width 840,
   кнопка «Новая заявка» в шапке, форма — диалог 640. На Medium (600–839) всегда диалог.
3. **Проверка полей** — только после первой попытки отправить, дальше обновляется при вводе. Имя — не пусто;
   телефон — 10–15 цифр, допускаются `+ ( ) -` и пробелы; проблема — не пусто, до 2000, счётчик с 1700.
4. **Отправка.** Этапы «Читаем настройки блока…» → «Отправляем заявку…», поля заблокированы, «Отмена» с
   пояснением «Если заявка уже ушла, она появится в списке.» Остановка → снекбар.
5. **Успех.** «Заявка №… отправлена» + номер для звонка, [Готово] → список, новая заявка сверху с подсветкой (4 с).
6. **Ошибки отправки** — баннер над кнопкой, введённое сохраняется: лимит («К заявкам», кнопка отправки скрыта),
   нет интернета / блок не читается / прочее — «Повторить». В демо повтор всегда успешен.
7. **Закрыть / отменить.** Подписи «Вопрос решён» (outlined) и «Отменить заявку» (текстовая, цвет error).
   Подтверждение → индикатор на карточке, кнопки заблокированы → статус меняется, снекбар.
8. **Черновик.** Закрытие формы с текстом проблемы → «Удалить черновик?» [Удалить] [Продолжить].
9. **Desktop:** Tab между полями, Ctrl/Cmd+Enter — отправить, Esc — закрыть диалог (подсказка под кнопкой).

## Список

- Активные (Открыта, В работе, Отложена) — карточка с фоном и тенью, текст 4 строки, контакт, действия.
  Завершённые — без фона, текст 2 строки, без контакта и действий.
- Группировка — 2 варианта: **секции** «Активные · N» / «Завершённые · N» и **фильтр-чипы** Активные / Завершённые / Все.
- Дата «13 ноября, 14:05»; не текущий год — «18 декабря 2025, 11:20».
- Состояния: скелетон 4 карточек, пусто (гарнитура из `tech_support.xml` + «Написать в чат»), ошибка первой
  загрузки, дозагрузка (индикатор внизу), ошибка дозагрузки («Не удалось загрузить» + «Повторить»).

## Статусы

| Статус | RU | EN | Тон |
|---|---|---|---|
| OPEN | Открыта | Open | primary-container |
| IN_PROCESS | В работе | In progress | success |
| SUSPENDED | Отложена | On hold | warn (локальный `--tr-warn*`) |
| FINISHED | Выполнена | Completed | нейтральный |
| FINISHED_BY_USER | Закрыта вами | Closed by you | нейтральный |
| CANCELED_BY_USER | Отменена вами | Cancelled by you | контурный, приглушённый |
