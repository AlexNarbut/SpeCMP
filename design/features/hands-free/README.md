# Озвучка шагов «Руки заняты» (hands-free)

Кнопка «Озвучка» на трёх экранах: обход, Clone, проверка системы. Экраны есть в двух видах: внутри мастера быстрого монтажа и самостоятельные (расширенный монтаж). Новых экранов нет.

- `HandsFree.jsx` — общий компонент: `HfVoiceIcon` (кнопка), `HfNoVoice` («Нет голоса»), `HfVoiceProvider` (фиксированные состояния для доски), `HF_TEXT` (тексты ru/en).
- `HandsFreeStates.html` — доска: состояния, 3 экрана в мастере и отдельно (телефон 412×840 и окно 1280×800), первое включение, «Нет голоса», «Повторить фразу», тексты. Светлая и тёмная темы.

## Решения
- **Место — шапка, справа (1a).** Круглая кнопка 48×48 в `actions` у `CmpTopAppBar`. Видна во всех фазах и не перекрывает карточку шага и док. На этапах Clone с блокировкой заблокирован только «назад», кнопка озвучки работает.
- **Состояния:** выкл (обводка, `volume_off`) · вкл (заливка primary, `volume_up`) · говорит (`graphic_eq` + кольцо-пульс 1,6 с, без пульса при reduced-motion) · нет голоса (обводка + красная точка, нажатие открывает «Нет голоса») · не поддерживается (кнопки нет).
- **Первое включение:** подсказка у кнопки, один раз. Закрывается кнопкой «Понятно» или сама через 7 с.
- **«Нет голоса»:** на телефоне — нижний лист, в широком окне — диалог. Android — кнопка «Установить голос» (системные настройки синтеза речи); iOS и desktop — путь в настройках и кнопка «Понятно».
- **Запоминание:** одно общее значение (`ps-hf-voice` в прототипе) для всех трёх экранов и следующих монтажей.
- **«Повторить фразу»** — нарисовано как предложение, в прототипах выключено (`?hfrepeat=1`).

## Где встроено
- `bypass-clone/BypassClone.jsx` — `Shell`, шапка.
- `check-state/CheckState.jsx` — обе шапки (обычная и низкая).
- `fast-mount/FastMount.jsx` — шапка мастера, только на шагах `bypass` и `clone`; проверка в мастере берёт шапку `CheckStateScreen`.
- В html-прототипах этих папок подключён `../hands-free/HandsFree.jsx` перед скриптом экрана. Без него экраны выглядят как раньше.

Демо-параметры: `?voice=none`, `?voice=unsupported`, `?hfos=ios|android|desktop`, `?lang=en`, `?hfrepeat=1`.

## Иконки
`volume_up`, `volume_off`, `graphic_eq`, `replay`, `voice_over_off` — Material Icons (Filled), как остальной набор. В `CMP_ICONS` / `CmpIconsResolver.kt` нужно добавить VolumeUp, VolumeOff, GraphicEq, Replay, VoiceOverOff.
