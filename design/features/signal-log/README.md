# Лог состояния

ТЗ: `uploads/signal-log-design-brief.md`. Служебный лог сигнализации, пока блок подключён по Bluetooth. Android, iOS, планшеты; на Desktop экрана нет (Desktop подключается только по USB).

- **SignalLog.dc.html** — интерактивный прототип. Сверху переключатели: окно (телефон 412×915 / планшет 800×1280 / планшет 1280×800), тема, связь, демо (пачка строк, пустой лог, загрузка), наличие техподдержки, результат отправки. Строки приходят сами, неравномерно.
  Пропсы (для встраивания): `scenario` (live | loading | empty | burst | paused | older | long | flash | offline | clear | share | share-filled | share-error | sending | send-fail | nosupport | sent | queued | saved | search | search-none | copy), `frame`, `theme`, `support`, `bare` (без панели демо, статично).
- **SignalLogStates.dc.html** — холст: P1 в светлой и тёмной, P2/P3, планшет, компоненты «Статус записи» и «Строка лога», плитка T1, анимации.
- Навигация: `psGo('signal-log')`, `psGo('signal-log-states')`.

## Экран
- Шапка: «Лог состояния», под ним «Pandora DX-4GS · ID 107131». Поиск — иконка (на планшете с подписью).
- Полоса статуса (всегда видна, 64 dp): «Идёт запись · N строк» с пульсом / «Пауза · пропущено N» + «Лента стоит, запись идёт» / «Нет связи — запись остановлена». Кнопка «Пауза» / «Продолжить» с подписью — в этой же полосе. Пока лог пуст или грузится, кнопки нет.
- Лента: время (Mono 2, вторичный цвет) | текст (Mono 1), перенос по любому символу. Новые снизу. Внизу — лента едет сама; прокрутил вверх — стоит, кнопка «↓ N новых» (без новых — «К последним»). Разделитель дня, когда лог переходит через полночь. Вверху: «Загружаем более ранние строки» → «Начало лога. Хранятся последние 10 000 строк».
- Долгий тап (на планшете с мышью — правый клик): строка выделяется, над ней «Копировать» 56 dp. Копируется «время текст».
- Поиск: поле в шапке, ↑/↓ по совпадениям, «3 из 12», фильтр «Только совпадения». Текущее совпадение — заливка акцентом, остальные — подсветка 24%.

## Действия
- Телефон и планшет 800: нижняя панель — «Очистить» (контур, слева) и «Поделиться» (заливка, справа).
- Планшет 1280: панель «Поделиться» справа (420 dp) постоянно, «Очистить лог» внизу панели. Планшет 800: как телефон, лист шириной до 640.
- Пока лог пуст — «Поделиться», «Очистить», поиск недоступны.

## Лист «Поделиться логом»
Пояснение → «Проблема» (обязательно, и для файла) → сводка «Будет передано N строк, с … по …» (весь лог блока, включая не подгруженные строки) → «Отправить в техподдержку» + «Сохранить в файл». Без техподдержки — одна основная «Сохранить в файл».
Результаты: отправлено / в очереди / файл сохранён — лист закрывается, снекбар. Ошибка — лист остаётся, плашка «Не удалось отправить», кнопка «Повторить отправку». Во время отправки — прогресс на нажатой кнопке, обе заблокированы.

## Плитка T1
Иконка `receipt_long`, «Лог состояния», «Почему не срабатывает тревога, автозапуск или датчик — по записям блока». Только при Bluetooth. Приписки о прошивке на плитке нет — она в пустом состоянии.

## Типографика
В шкалу добавлены `--t-mono1-*` (16/22, текст строки) и `--t-mono2-*` (14/18, время), Roboto Mono 500.
