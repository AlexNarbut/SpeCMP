# Обновление приложения (app-update)

ТЗ: `uploads/app-update-design-brief.md`. Desktop (Windows, macOS) — проверка, загрузка, установка, каналы обновлений.
Телефон и планшет (Android, iOS) — описание новой версии и переход в магазин, каналов и загрузки нет.

## Файлы
- **AppUpdateScreen.jsx** — весь UI и логика, экспорт `window.AppUpdate`:
  - `useUpdateCtl({ platform, initial, inst0, chans, ch0, sizeKnown, busy, dialog0 })` — контроллер: состояние, канал, загрузка, диалоги. Один экземпляр на главный и экран обновления — загрузка идёт в фоне.
  - `UpdateBody` / `UpdateRoute` — тело экрана (топбар даёт хост). `UpdateDialogs` — диалоги. `AppUpdateApp` — полный экран.
  - Входы на главном: `SideUpdateBlock`, `UpdateToast` (desktop), `UpdateBanner`, `MenuUpdateRow` (телефон/планшет), `RequiredUpdateButton` (топбар).
  - `platform`: `win` | `mac` | `android` | `ios`.
- **AppUpdate.html** — desktop: прототип и закреплённые состояния, Windows/macOS, окно 1280×800 и мин. 800×600, 1 / 3 / 6 каналов, раскладка каналов, размер известен/нет, «Идёт работа с блоком», диалоги.
- **AppUpdatePhone.dc.html** — телефон 412×840 и планшет 800×1280, Android/iOS, прототип и состояния.
- **AppUpdateStates.dc.html** — все состояния на одном холсте (desktop, каналы, диалоги, тёмная тема, телефон, планшет, входы на главном).
- Навигация `res/nav.js`: `app-update`, `app-update-phone`, `app-update-states`.

## Входы
- **Desktop:** меню «Проверить обновления» → экран + новая проверка. Блок внизу бокового бара (доступна / загрузка с прогрессом / «Обновление загружено» + «Установить»). Уведомление при старте «Доступна версия 2.1.0» + «Обновить» (запускает загрузку и открывает экран) — один раз за запуск, само скрывается через 8 с. Значок «Нужно обновить приложение» в топбаре.
- **Телефон/планшет:** закрываемая плашка «Доступна новая версия 2.1.0» в начале главного (крестик скрывает до следующей новой версии) **и** пункт меню «Обновление приложения» с точкой, пока есть новая версия. Значок «Нужно обновить приложение» в топбаре.
- Открытие из меню проверяет заново (кроме идущей загрузки/установки). Из плашки, уведомления, блока — показывает текущее состояние. «Позже» — только если экран открыт не из меню.

## Экран
Сверху — «Установлена версия 2.0.4 (204)», мелко «база настроек s1234», на desktop с несколькими каналами — «Канал: Релиз».

Состояния desktop:
1. **Проверка** — «Проверяем обновления», канал.
2. **Доступна** — пилюли «Установлена → Новая», дата, размер (если известен), «Обновить» / «Скачать файл» (сохранить установщик в выбранную папку) / «Позже». «Что нового» — простой текст: «-» маркер, пустая строка — отступ, остальные строки — подзаголовки; длиннее 8 строк сворачивается до 6 с «Показать полностью». Пустое — секции нет.
3. **Загрузка** — определённый прогресс «43 из 180 МБ · 24 %» и неопределённый «43 МБ загружено» (сейчас SDK размер не отдаёт). «Отменить». Подпись «Можно вернуться на главный экран — загрузка продолжится» (фоновая загрузка — отдельная доработка; пока уход с экрана отменяет загрузку, подпись не показывать).
4. **Загружено** — «Установить и перезапустить» / «Позже», под кнопкой «Приложение закроется, установит обновление и откроется снова.» + одна подсказка по ОС (Windows — окно установщика; macOS — без окон).
5. **Установка запущена** — «Устанавливаем обновление…», 1–3 с. Если идёт работа с блоком — сначала диалог «Идёт работа с блоком · Обновиться сейчас? Соединение будет прервано.» — «Отмена» / «Обновить».
6. **Последняя версия** — «У вас последняя версия», канал, «Проверить снова».
7. **Ошибки** (нейтрально, кроме сбоя загрузки): нет сети, ошибка сервера («Повторить»); «В канале «X» пока нет версий» («Проверить снова»); загрузка прервалась («Повторить» — заново, «Скачать файл»); файл не подходит («Скачать файл»).

Телефон: проверка, доступна («Открыть в Google Play» / «Открыть в App Store», иконка «открыть во внешнем», «Позже»; подпись «Если обновление ещё не появилось в магазине, попробуйте позже.»), последняя версия, нет сети, ошибка сервера.

## Каналы (только desktop)
- Секция «Канал обновлений» — радио-строки: название как есть (переносится), под ним «Версия 2.2.0 · 10.11.2026», «· установлена» или «Пока нет версий». Под списком — «Бета — новые функции раньше всех, но возможны ошибки».
- Один канал — секции нет. Во время загрузки и установки выбор недоступен.
- Смена канала сразу запускает проверку. Переход на не-релизный канал — короткий диалог «Перейти на канал «Бета»?» — «Отмена» / «Перейти». Обратно на релиз — без диалога.
- Отката нет: если в канале версия старше установленной — «Обновлений нет» + «В канале «Релиз» сейчас 2.1.0 — она старше установленной. Обновление придёт, когда в канале выйдет версия новее.»
- Раскладка — два варианта на выбор: **каналы справа** (две колонки, ≥ 840 dp, max-width 1040) и **каналы ниже** (одна колонка, max-width 720). В окне < 840 dp — всегда ниже.

## Адаптив
Compact — одна колонка, отступы 16. Medium (планшет) — отступы 24, max-width 720. Expanded — см. «Каналы». Кнопки — высота 48.
