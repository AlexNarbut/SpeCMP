# Быстрый монтаж (fast-mount)

Мастер пошаговой установки сигнализации по облачной конфигурации. Источник — `uploads/fast-mount-design-brief.md`.
Точка входа — плитка «Быстрый монтаж» на главной.

## Файлы
- `FastMount.jsx` — весь мастер: каркас, колонка шагов (W1), экраны F1–F17, пресеты, демо-панель.
- `FastMount.html` — телефон 412×840, кликабельный прототип.
- `FastMountTablet.html` — планшет 1280×800 / 800×1280 / телефон-ландшафт 915×412.
- `FastMountDesktop.html` — окно 1280×800 и минимум 800×600.
- `FastMountStates.html` — доска всех состояний (замороженные превью) + W1 и анимация Clone.
- Параметры URL: `?state=F8b&theme=dark`.

## Каркас
- < 760: обычный topbar (шаг · «Модель · ID блока»), закреплённая панель с главной кнопкой. Шагов нет.
- ≥ 760: вариант **B** — колонка шагов слева (264 / 300 при ≥ 1000), справа topbar + контент (max-width 760–1040) + панель.
- Подготовка в колонке — одна точка с подшагами «Блок → Автомобиль → Конфигурация → Сводка».
- Статусы: пройден ✓ · текущий (подложка secondary-container) · впереди · по необходимости (Clone пунктиром, «Если потребуется обходу») · пропущен («Не потребовался») · следующий после перезагрузки (пульсирует).
- Перезагрузка — «бегущая» линия под завершённым шагом + плашка «Перезагрузка · м:сс». Экран: таймер, «Не отключайте питание», «Далее: …». 60 с без ответа → «Потеря связи».
- Clone: при итоге обхода «нужен Clone» строка плавно разворачивается в обычный шаг со вспышкой.
- USB: без Slave и проверки системы; в сводке — плашка.
- «Назад»: замок на «Готовим монтаж», записи, перезагрузке, процессе обхода/Clone; диалоги «Выйти из быстрого монтажа?» (монтаж, ошибка записи), «Вернуться к монтажу?» (обход/Clone до старта и на итоге), «Вернуться к предыдущему шагу?» (проверка системы). На «Готово» — нет.
- Главная кнопка в ожидании ответа — спиннер, повторный тап невозможен.

## Зависимости
- Проверка системы — `../check-state/CheckState.jsx` (`mode="quick"`, `onDone`, строгий порядок заданий). На странице нужен `window.CS_BASE = "../check-state/"`.
- Иллюстрации обхода/Clone — `../bypass-clone/illus/*.svg`. Остальные — плейсхолдеры под художника.
- Каталог автомобилей и список конфигураций в прототипе упрощены — в продукте это существующие экраны `vehicle-select` и `configurator`.
