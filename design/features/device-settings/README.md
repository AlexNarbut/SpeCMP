# Настройки устройства (device-settings)

Редактор расширенных настроек: Устройство → Расширенный монтаж → «Расширенные настройки». ТЗ — `uploads/device-settings-design-brief.md`.

Файлы: `DeviceSettings.jsx` (экран + строки + редакторы + диалоги), `ds-demo.jsx` (панель сценариев),
`DeviceSettings.html` (mobile) · `Tablet.html` · `Desktop.html` · `Parts.html` (строки 13 типов × состояния, новые компоненты).

Раскладка: compact — переход по разделам + крошки, шторка; medium/expanded — дерево + раздел, диалог.
Принятые по умолчанию решения по п.10 ТЗ: при обрыве правки сохраняются и предлагаются к записи; сегменты ≤3 варианта по ≤6 символов;
один уровень на desktop; пометка «служебных» настроек не делается.
