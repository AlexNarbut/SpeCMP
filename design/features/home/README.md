# Главный экран (home)

Рабочая стартовая панель монтажника Pandora Спец. По ТЗ `uploads/design-brief.md`.

## Файлы

- **HomeScreens.jsx** — презентационный экран и блоки, только из Cmp*-компонентов ДС:
  `HomeScreen` (chrome + drawer + контент), `HomeTopBar`, `HomeDrawer`, `ProfileBlock`,
  `MainActionCard`, `ToolCard`, `StatusChip`, `IconTile`, хук `useHomeMode`.
  Данные: `MAIN_ACTIONS`, `TOOLS`, `PROFILES`, карта иконок `ICON`.
- **Home.jsx** — `HomeApp`: живой интерактивный экран. Владеет меню (открыто/закрыто) и
  синхронизацией; тема / вариант карточек / профиль — управляются из хоста (контролируемые).
- **Home.html** — Compact / телефон (Android-фрейм 412×840).
- **HomeTablet.html** — планшет: портрет 800×1280 (Medium) / ландшафт 1280×800 (Expanded).
- **HomeDesktop.html** — окно Compose Desktop: Expanded 1100×760 / Large 1280×800, меню откр/закр.
- **HomeParts.html** — все блоки по отдельности + галерея состояний (default/hover/focus/pressed/disabled).

## Состояние загрузки

`HomeApp` показывает загрузку при входе (`initialLoading`, ~1.5с), затем раскрывает панель.
`HomeScreen loading` рендерит `HomeSkeleton` (скелетон-плейсхолдеры в раскладке карточек,
перестраиваются по брейкпоинтам) + тонкий `CmpLinearProgressIndicator` под топбаром; статус и меню
на время загрузки скрыты. В хостах — кнопка «↻ Загрузка» для повтора (remount по key).

## Обновление приложения (все платформы)

Источник правды — `features/app-update/` (README там). Все хосты главного подгружают
`../app-update/AppUpdateScreen.jsx`; `HomeApp` держит один `useUpdateCtl` на главный и route `update`,
поэтому загрузка идёт в фоне.

- **Desktop:** меню «Проверить обновления» → экран с новой проверкой. Внизу бокового бара — `SideUpdateBlock`:
  «Доступна новая версия» → «Загрузка 2.1.0» с прогрессом → «Обновление загружено» + «Установить». При старте —
  `UpdateToast` «Доступна версия 2.1.0» + «Обновить», один раз за запуск.
- **Телефон/планшет:** закрываемая плашка `UpdateBanner` в начале контента и пункт меню
  `MenuUpdateRow` «Обновление приложения» с точкой, пока есть новая версия.
- **Топбар:** `updateRequired` → значок «Нужно обновить приложение» с точкой → экран (в `Home.html` — переключатель).
- Проп `initialUpdateState` (`available` по умолчанию) — стартовое состояние обновления.

## Адаптив (Window Size Classes по ширине контейнера)

- **compact** (<600) — основные карточки 1 колонка, инструменты — строки; меню modal со scrim.
- **medium** (600–839) — карточки 2 кол, инструменты 2 кол; меню modal.
- **expanded** (840–1199) — карточки 2 кол, инструменты 3 кол; меню — боковая панель.
- **large** (≥1200) — карточки 2 кол, инструменты 4 кол; меню — боковая панель.

## Ключевые решения по ТЗ

- Нет видимых заголовков «Монтаж» / «Инструменты»; статус `База обновлена` — в топбаре.
- Две равнозначные основные карточки, без нижних CTA и пустого места под ними.
- Меню без заголовка «Меню» и без крестика; закрытие — scrim / кнопка меню. Версия ПО внизу.
- Раздел «Статьи» отсутствует.
- 2 варианта основных карточек: `centered` (иконка сверху) и `leading` (иконка слева) — тумблер в хостах.

## Навигация

Ключи `res/nav.js`: `home`, `home-tablet`, `home-desktop`, `home-parts`.

## Иконки

Основные карточки и инструменты — реальные SVG из старого проекта (`main_*`), инлайнятся через
`res/icons/main-icons.js` и наследуют `currentColor` (адаптация к теме). Двухцветные
`fast_mount`/`adv_mount` восстановлены (базовые слои opacity .3, деталь — полный тон). Полный набор
старых иконок — в `res/icons/legacy/`. Иконки чрома (меню/тема/синхронизация/настройки/выход/статус) —
лигатуры Material Icons.
