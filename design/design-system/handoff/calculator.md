# Handoff — экран «Калькулятор»

Спека для разработки экрана калькулятора (источник истины по UI — макеты
`features/calculator/`). Реализация в реальном коде — `feature/calculator` в SpeCMP.

## Что это
Инженерный калькулятор монтажника с **таймером установки**. Один экран, работает на всех трёх
платформах из единой композиции; различается только системная зона (статус-бар / окно ОС).

## Раскладка (сверху вниз)
1. **CmpTopAppBar** — заголовок «Калькулятор», слева кнопка «Назад» (`CmpIconButton ArrowBack`)
   на mobile; на desktop кнопка «Назад» скрыта (`showBack=false`).
2. **Таймер** — крупное моноширинное время `mm:ss` / `hh:mm:ss` (36sp, Light). Под ним строка
   кнопок: «Старт» (`primaryContainer`) или «Стоп» (`secondaryContainer`) + «Сброс»
   (`surfaceVariant`). Высота кнопок 40 dp, радиус 12.
3. **Дисплей** — справа: строка операции (16sp, `onBackground` 50%) и результат (64sp, Light;
   40sp если длина > 9 символов), моноширинный, обрезка по одной строке.
4. **Клавиатура** — сетка 4 столбца, gap 8, клавиши `CmpSurface` (clickable), высота 72, радиус 16,
   текст 24sp:
   - `C` `⌫` — `surfaceVariant`/`onSurfaceVariant`
   - `÷ × − +` — `secondaryContainer`/`onSecondaryContainer`
   - цифры и `.` — `surface`/`onSurface`
   - `=` — `primaryContainer`/`onPrimaryContainer`
   - `0` занимает 2 колонки.

## Поведение
- Деление на ноль → снэкбар «Деление на ноль невозможно», состояние сбрасывается.
- Таймер тикает раз в секунду; «Сброс» останавливает и обнуляет.

## Токены / правила
- Только роли цвета (`--primary`, `--secondary-container`, `--surface`, …); обе темы.
- Зона касания клавиш ≥ 48 dp по факту (72 dp по высоте) — критично для механиков.
- Desktop: экран центрируется в колонке ~460 px внутри опорного окна 800×600, без горизонтального
  скролла; состояния hover/focus активны.

## Файлы-макеты
- `features/calculator/Calculator.jsx` — компонент `CalculatorScreen` (логика + раскладка).
- `features/calculator/Calculator.html` — mobile-обёртка (Android-фрейм, переключение тем).
- `features/calculator/CalculatorDesktop.html` — desktop-обёртка (окно 800×600).
