# CmpHoldToConfirmButton
Опасные действия: сброс, стирание, прошивка. Пользователь удерживает кнопку `duration` мс, заливка идёт слева направо, отпускание отменяет.
```jsx
<CmpHoldToConfirmButton text="Удерживайте для сброса" doneText="Сброшено" onConfirm={reset} />
```
Не заменяйте ей обычные подтверждения — только необратимые операции.
