# Хендофф: fast-mount, check-state, home — 2026-11-02

Эта папка — распакованная выгрузка макетов Pandora Spec. Реализуй в коде только то, что описано ниже.
Все пути указаны относительно корня этой папки.

## Область (что реализуем)
- Новый мастер «Быстрый монтаж» (`fast-mount`): подготовка → запись настроек → монтаж → [перезагрузка] → обход → Clone? → Slave → проверка системы → отзыв → готово.
- Каркас мастера: телефон (topbar + закреплённая панель), планшет/desktop (колонка шагов слева — W1).
- Правка `check-state`: строгий порядок заданий в режиме `quick` («Текущее задание» / «Ожидает»), колбэк завершения шага, широкая раскладка (горизонтальный пульт, «Подробно» вкладками, справа чек-лист/команды).
- `home`: плитка «Быстрый монтаж» ведёт в мастер.

## Контекст и намерение

## Ключевые правила
- Каркас: < 760 dp — topbar «шаг · Модель · ID», шагов нет; ≥ 760 — колонка шагов (≥1100: 300 dp; 900–1099: 264; 760–899: компактная 88, только номера). Невысокое окно (< 860) — без карточки авто внизу колонки.
- Две колонки контента — только при ширине контента ≥ 860 dp; иначе одна колонка с max-width.
- Статусы шага: done · current · ahead · optional (Clone, пунктир) · skipped · next (после перезагрузки, пульсирует). Пройденный шаг не навигационный — тап показывает справку.
- Перезагрузка — не шаг: бегущая линия под завершённым шагом + экран с таймером; 60 с без ответа → «Потеря связи».
- Clone появляется анимацией, когда обход вернул «нужен Clone»; по USB нет Slave и проверки системы.
- «Назад»: замок на подготовке монтажа, записи, перезагрузке, процессе обхода/Clone; диалоги «Выйти из быстрого монтажа?», «Вернуться к монтажу?», «Вернуться к предыдущему шагу?»; на «Готово» — нет.
- Главная кнопка при ожидании ответа — спиннер, повторный тап невозможен. Ошибка шага — плашка с причиной и действием.

## Дизайн-система (обязательно соблюдать)
- Токены: design-system/styles.css + tokens/* — только `--*`, без хардкода цветов/размеров.
- Темы: Light / Dark через `data-theme`.
- Иконки: Material Icons (Filled) через каталог CmpIcons (res/icons/cmp-icons.js).
- Зона касания ≥ 48 dp; состояния hover/focus для Desktop.
- Компоненты: components/** (`CmpTopAppBar`, `CmpButton`, `CmpOutlinedButton`, `CmpTextButton`, `CmpSurface`, `CmpCheckbox`, `CmpSnackbar`, `CmpTabRow`, `CmpCircularProgressIndicator`) — см. `.prompt.md` и `.d.ts`.

## Зависимости / общие части
- Иллюстрации обхода и Clone — features/bypass-clone/illus/*.svg (красятся currentColor).
- Проверка системы встраивается из features/check-state (режим `quick`); иконки/силуэт — features/check-state/icons, vehicle.
- Существующие экраны, на которые ссылается мастер: device-select (поиск), firmware (обновление), vehicle-select, configurator, bypass-clone, support-chat.

## Как смотреть макеты
Открыть HTML-файлы в браузере. Состояние — параметр `?state=F8b`, тема — `?theme=dark`. Доска — `features/fast-mount/FastMountStates.html`.

## Чек-лист реализации
- [ ] UI совпадает с макетом в светлой и тёмной теме на телефоне, планшете (портрет/ландшафт) и desktop (1280×800 и 800×600).
- [ ] Только токены `--*`, без инлайновых цветов.
- [ ] Хит-таргеты ≥ 48 dp, тексты читаемы.
- [ ] Правила «Назад» и диалоги — по таблице.
- [ ] Набор шагов строится из SDK; Clone вставляется по требованию обхода; USB без Slave/проверки.
- [ ] Перезагрузка с таймером и переходом в «Потерю связи» через 60 с.
- [ ] Проверка системы: задания строго по порядку.

## Не входит в задачу
- Каталог автомобилей и список облачных конфигураций — существующие экраны (в прототипе упрощены).
- Экраны обхода/Clone целиком — меняются только состояния итога и ошибки в режиме мастера.
- Экран «Потеря связи» и диалог PIN — существующие.
