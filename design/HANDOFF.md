# Хендофф: главный экран (home) — 2026-07-08

Эта папка — распакованная выгрузка макетов Pandora Спец. Реализуй в коде только то, что описано ниже.
Все пути указаны относительно корня этой папки.

## Область (что реализуем)
- **Главный экран** — рабочая стартовая панель монтажника (`features/home/`).
- Топбар (64dp): кнопка меню слева, `Pandora Спец` по центру, статус `База обновлена` справа
  (на compact сворачивается в иконку; при синхронизации — спиннер + `Обновление…`).
- Боковое меню (drawer): профиль (аватар/имя/email, поддержка неполного профиля), переключение
  темы, обновление базы, настройки, выход, версия ПО внизу. Без заголовка «Меню», без крестика.
  Compact/Medium — modal со scrim; Expanded/Large — постоянная боковая панель.
- Два равнозначных сценария: `Быстрый монтаж` / `Расширенный монтаж` (крупные action-карточки,
  только иконка+название+описание, без нижних CTA).
- Сетка вспомогательных инструментов без заголовка: Конфигуратор, Архив прошивок, Автомобили,
  Заявки, Обратная связь, Информация о товаре.
- Состояние загрузки экрана (скелетоны + linear progress под топбаром).
- 2 варианта основных карточек: `centered` / `leading`.

## Контекст и намерение
Главный экран — не витрина возможностей, а спокойная рабочая панель: два основных сценария сверху,
вспомогательные инструменты ниже, системные действия в боковом меню, статус данных в топбаре.
Материал 3, тёмная и светлая темы, крупные зоны касания (пользователи — автомеханики).

## Адаптивность (Window Size Classes по ширине окна в dp)
- **Compact** (<600): основные карточки 1 колонка, инструменты — вертикальные строки; меню modal.
- **Medium** (600–839): карточки 2 колонки, инструменты 2; меню modal.
- **Expanded** (840–1199): карточки 2, инструменты 3; меню — боковая панель.
- **Large** (≥1200): карточки 2, инструменты 4; меню — боковая панель.
- Контент центрируется с `max-width` ≈1040 на Expanded/Large.

## Дизайн-система (обязательно соблюдать)
- Токены: `design-system/styles.css` + `design-system/tokens/*` — только `--*`, без хардкода
  цветов/размеров/радиусов.
- Темы: Light / Dark через атрибут `data-theme` (dark — основная).
- Компоненты (обёртки Material 3), их `.prompt.md` и `.d.ts` — ценны для дева:
  - `components/navigation/CmpTopAppBar`
  - `components/buttons/CmpIconButton`, `CmpButton`, `CmpTextButton`
  - `components/surfaces/CmpSurface`, `CmpDivider`
  - `components/forms/CmpSwitch`
  - `components/progress/CmpCircularProgressIndicator`, `CmpLinearProgressIndicator`
  - `components/app-kit/CmpText`, `CmpIcon`, `useStateLayer`, `PhoneFrame.jsx` (фрейм устройства)
- Иконки:
  - чром (меню, тема, синхронизация, настройки, выход, статус) — Material Icons (Filled) через
    каталог CmpIcons (`res/icons/cmp-icons.js`);
  - иконки основных карточек и инструментов — реальные SVG из старого проекта в `res/icons/main/`,
    инлайнятся через `res/icons/main-icons.js` (наследуют `currentColor`). Двухцветные
    `fast_mount`/`adv_mount` — базовые слои opacity .3, деталь — полный тон. Архив старых иконок —
    `res/icons/legacy/`.
- Зона касания ≥ 48 dp; состояния hover/focus для Desktop; крупная типографика.

## Зависимости / общие части
- `res/nav.js` — кросс-макетная навигация (`window.psGo('home' | 'home-tablet' | 'home-desktop' | 'home-parts')`).
- `res/icons/main-icons.js`, `res/icons/main/`, `res/icons/legacy/` — иконки главного экрана.
- `_ds_bundle.js` — скомпилированная дизайн-система (компоненты `window.PandoraSpecDesignSystem_b8d6e1`).
- `design-system/handoff/` — общие спеки, если релевантны.

## Как смотреть макеты
Открыть HTML-файлы главного экрана в браузере (автономные React+Babel прототипы). В каждом есть
тумблеры темы, варианта карточек, профиля, а также «↻ Загрузка» для повтора состояния загрузки.
`HomeDesktop.html` показывает боковую панель меню и переключатели Expanded/Large + меню откр/закр.

## Чек-лист реализации
- [ ] UI совпадает с макетом в светлой и тёмной теме на Compact / Medium / Expanded / Large.
- [ ] Только токены `--*`, без инлайновых цветов/размеров.
- [ ] Хит-таргеты ≥ 48 dp, тексты читаемы, названия инструментов не обрезаются.
- [ ] Две основные карточки равнозначны, без нижних CTA и пустого места под ними.
- [ ] Меню без заголовка «Меню» и крестика; версия ПО внизу; неполный профиль обрабатывается.
- [ ] Нет заголовков «Монтаж»/«Инструменты»; раздел «Статьи» отсутствует; статус — в топбаре.
- [ ] Состояние загрузки (скелетоны + linear progress) отрабатывает при входе.

## Не входит в задачу
- **Экран обновления приложения** (`features/app-update/`) — отдельная фича, свой хендофф.
  На главном экране (desktop) есть только вход в него (строка «Проверить обновления» и блок
  «Доступна новая версия» в боковом меню); сам раздел обновления реализуется отдельно.
- Экраны авторизации (`features/auth/`) и калькулятора (`features/calculator/`) — не трогаем.

## Заметки / открытые вопросы
- Иконки главного экрана — реальные SVG из старого проекта; если появятся обновлённые ассеты,
  заменить карту в `res/icons/main-icons.js` (и файлы в `res/icons/main/`).
- Длительность имитации загрузки — проп `loadMs` в `HomeApp` (в проде — реальная готовность данных).
- Навигация карточек/инструментов в прототипе — заглушки (`onNav`); подключить реальные маршруты.
