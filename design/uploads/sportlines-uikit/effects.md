# Эффекты и анимация

Блюр, стекло, свечения и тайминги — то, что делает этот визуальный язык узнаваемым. Значения из кода `core:design`; пресеты HazeMaterials (thin/thick/ultraThin/ultraThick) — внутренние значения библиотеки haze 2.1.0, в репозитории их нет.

## Стекло — `glassSurface`

Подложка круглых кнопок топбара (`TopBarIcon` 56dp) и пилюли `VerticalSwitcher`.

| Параметр | Значение |
|---|---|
| Блюр фона | 32dp, без тинта, noise 0 |
| Оверлей | вертикальный градиент: прозрачный → `foreground-on-dark-ultra-highlight` (5%) |
| Рамка | 1dp, вертикальный градиент `foreground-on-dark-medium-highlight` (15%) → `foreground-on-dark-highlight` (10%) |
| Форма | круг (или пилюля) |
| Фолбэк без блюра | `background-page-primary` @ 60% |

В Figma: Background blur 32 + fill linear (0% → white 5%) + stroke 1 inside, linear white 15% → 10%.

## Полосы блюра у краёв (топбар, нижняя панель)

- Топбар прозрачный (`background-page-transparent`). Когда контент уезжает под него, появляется **прогрессивный блюр**: плотный у верхнего края, к низу полосы сходит на нет. Тинт — `background-page-primary`, материал `thick`.
- Нижняя панель — зеркально: плотная снизу, материал `ultraThick` (плотнее, чтобы контент не читался сквозь табы).
- Нарастание: по скроллу за первые **80dp**; у сворачивающегося топбара — только когда он свёрнут на ≥95%.
- Под статус-баром: `ultraThin` с тем же прогрессивным профилем.
- Фолбэк (энергосбережение): вертикальный градиент цвета страницы, 92% у края, держится 60% высоты полосы, потом до 0.
- Альтернатива блюру: `fadeUnderTopBar` — контент растворяется маской со стопами альфы [0, 0, 0.2, 0.4, 0.72, 1] по высоте топбара.

## Модальная подложка

- Под модалками, полноэкранными алертами и шторками весь экран размывается: **блюр 64dp** + тинт `background-overlay` (чёрный 60%).
- Без блюра: `background-page-primary` @ 90%.
- В Figma: Layer blur 64 на снимке экрана + прямоугольник #000000 60%.

## Фон экрана — радиальное свечение

`AppBackground` / `GradientState`:

| Параметр | Значение |
|---|---|
| База | `background-page-primary` |
| Свечение | радиальный градиент от цвета @ **25%** к цвету страницы |
| Цвета | `gradient-brand` (загрузка), `gradient-success`, `gradient-info`, `gradient-warning`, кастомный или выключено |
| Центр | по горизонтали — центр; по вертикали Top 0 / Center 0.5 / Bottom 1.0 высоты |
| Радиус | 0.5 × большей стороны экрана |
| Переход цвета/позиции | 600ms tween |
| Появление | fade-in 300ms после задержки 300ms; при сворачивании хедера гаснет |
| Фото-слой (опц.) | crop, градиент-оверлей: 0 — цвет страницы, 0.17–0.41 — прозрачно, 1.0 — цвет страницы |

Экран успеха (`SuccessScaffold`): радиальный `brand-primary-default` @ 10%, центр (0.5, 0.4), радиус 0.8 × большей стороны, поверх — конфетти.

Фон меняется по состоянию экрана: загрузка — brand по центру, ошибка — info, контент — выключено.

## Свечение рамки — `glowingBorder`

Drop shadow цветом акцента: радиус 20dp, скругление 8dp. Утилита, не токен.

## Скелетоны и лоадеры

- **Спиннер** `SpinningProgressBar`: 30dp, 8 скруглённых палочек (30% ширины × 1/8 высоты). Базовый цвет `foreground-on-dark-light` (20%), бегущий хвост из 4 палочек белого с альфой 0.4 / 0.6 / 0.8 / 1.0. Полный оборот 640ms, шагами, линейно.
- **TriangleLoader** (скелетон карточки/слота): 4 треугольника сходятся в центре. Заливка `background-surface-primary`, альфа по кругу 10% → 7% → 3% → 2%, сдвиг на четверть цикла по часовой, цикл 2000ms. Диагонали 0.5dp, градиент 10% → 2%.
- **Правило:** весь экран или таб — спиннер по центру, место одного элемента — скелетон.
- Логотип-лоадер (Lottie) шириной 197dp — для долгих ожиданий.

| Что | Длительность / кривая |

| Нажатие (scale 0.96) | spring по умолчанию |
| Цвет Tabs / SegmentedTabs | 600ms tween |
| Цвет Chips | 300ms tween |
| Автоскролл таб-ряда к выбранному | 300ms |
| Тост — въезд/выезд сверху | 300ms; висит 3000ms |
| Шторка — въезд снизу | 300ms tween |
| BlurredOverlay — fade + slide справа | 600ms |
| Смена фона-свечения | 600ms |
| LCE: смена загрузка/ошибка/контент | out 500ms → in 500ms (задержка 300); crossfade 300ms |
| VerticalSwitcher | 400ms FastOutSlowIn |
| Нижняя панель: масштаб иконки/подписи | 400ms |
| HoldToConfirm заливка | 1500ms linear + пауза 200ms на 100% |
| Мигание курсора OTP | 500ms туда-обратно |

| Плавающая кнопка — притухание | через 3s простоя до 60% за 300ms |

## Производительность (для разработки)

Живой блюр дорог. Один блюр на экран — норма. В режиме экономии заряда всё деградирует до заливок (фолбэки выше). На iOS шум блюра отключён, элементы списков используют заливку вместо блюра.
