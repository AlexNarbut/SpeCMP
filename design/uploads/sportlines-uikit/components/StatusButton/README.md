# StatusButton

Кнопка статусного действия (например, «Удалить аккаунт»). Выглядит как Tertiary S, но окрашена статусом. Высота 40 фиксированная, паддинг 12, `headLine3`, UPPERCASE, scale 0.96. Пока один тип — `Warning`; Success/Error добавляются тем же набором токенов.
