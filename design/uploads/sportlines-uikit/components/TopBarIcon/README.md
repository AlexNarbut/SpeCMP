# TopBarIcon

Круглая стеклянная кнопка 56 в топбаре: «Назад», «Закрыть», действия. Иконка 24 (`icon-m`), цвет `foreground-on-dark-primary-default`. Подложка — `glassSurface`: блюр 32, градиент 0 → `foreground-on-dark-ultra-highlight`, рамка 1px с градиентом `foreground-on-dark-medium-highlight` → `foreground-on-dark-highlight`. Без блюра — заливка `background-page-primary` @ 60%.

Обычная `IconButton` — тап-зона 48–56 без подложки, ripple круглый.
