# Toggle

Переключатель. Трек 40×22, полностью скруглённый, бегунок 18, отступ 2.

| | Трек | Бегунок |
|---|---|---|
| Вкл | `brand-primary-default` (pressed `brand-primary-pressed`) | `static-white` |
| Выкл | `background-surface-light` (pressed `background-surface-highlight`) | `background-surface-tertiary` |

Без ripple и scale, анимация цвета и положения — пружина по умолчанию.
