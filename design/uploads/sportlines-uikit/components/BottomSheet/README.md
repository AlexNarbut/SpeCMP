# BottomSheet

Нижняя шторка. Панель во всю ширину, фон `background-page-primary`, **углы прямые** (в 1x2 — `r-card-large-radius`), без ручки-«хватателя». Под ней — тот же фон, что у Modal: блюр 64 + `background-overlay`. Въезд и выезд 300ms.

**Шапка:** паддинг 16 сверху/снизу, 8 по бокам; заголовок `headLine1` по центру, 1 строка, отступ 32; крестик — IconButton 56 с иконкой `close` 32 справа. Тап по фону и «Назад» закрывают шторку.
