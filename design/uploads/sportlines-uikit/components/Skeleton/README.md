# Skeleton

`TriangleLoader` — скелетон карточки или слота картинки. Четыре треугольника сходятся в центре, каждый — линейный градиент `background-surface-primary` от α к α×0.3 к своему краю. Альфа ходит по кругу 10% → 7% → 3% → 2% со сдвигом на четверть цикла по часовой, цикл 2000ms. Диагонали 0.5, градиент 10% → 2%.

Вариант `ContentPlaceholder` — по центру мерцает знак бренда (Lottie, цвет `background-surface-primary`). Ширина знака от меньшей стороны: баннер 0.25, плитка 0.31, медиа 0.5, иконка 0.66.
