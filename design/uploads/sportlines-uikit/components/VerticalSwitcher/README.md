# VerticalSwitcher

Стеклянная пилюля-переключатель из 2+ иконок. Для 2 иконок — 108×56, паддинг 6, слоты 44 с зазором 8. Активная иконка 44 и alpha 1, неактивная масштаб 32/44 и alpha 0.5. Переход 400ms FastOutSlowIn. Фон — `glassSurface`, без ripple. В SpeCMP подходит для переключения «список / карта» и т.п.
