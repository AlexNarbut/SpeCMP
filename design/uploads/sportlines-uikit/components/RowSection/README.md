# RowSection

Крупная навигационная секция (пункты главного меню, разделы настроек). Мин. высота 96 (с подзаголовком ≈111), паддинг 32 со всех сторон, зазор 8. Заголовок `headLine1`, 2 строки; подзаголовок `paragraph2` цвета `brand-primary-default`, 2 строки. Опц. точка-индикатор 16. Справа `pyromid-right` 32. Разделитель **сверху**, с отступом 32 по бокам. Disabled — стрелка скрыта, клик выключен. Нажатие — scale 0.96 + ripple.
