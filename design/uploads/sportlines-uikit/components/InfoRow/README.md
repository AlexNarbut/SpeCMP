# InfoRow

Строка «лейбл → значение» для карточек данных. Мин. высота 88, отступ сверху 20, снизу 24, зазор лейбл↔значение 4. Лейбл `additional0` `foreground-on-dark-secondary-default`, 1 строка. Значение `headLine2` `foreground-on-dark-primary-default`, многострочное. Опц. иконка 32 справа (кликабельная — в IconButton 56, например «копировать»). Снизу разделитель во всю ширину: `w-list-item-width`, `border-light`.

Для SpeCMP: экран информации об устройстве — серийный номер, версия прошивки, IMEI.
