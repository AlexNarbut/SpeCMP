# InputDigit

OTP / код подтверждения из N ячеек. Ячейка — макс. ширина 44, пропорция 44:72, сжимается под ширину. Зазор зависит от ширины экрана: меньше 340 — 8, меньше 380 — 12, иначе 16. Ряд по центру.

Каждая ячейка использует токены InputCenter. Текущая ячейка — в состоянии Active. Цифра — `title1` (32) по центру. В пустой текущей ячейке мигает курсор 3×24 (alpha 1↔0, 500ms). Хинт под рядом с зазором 12.
