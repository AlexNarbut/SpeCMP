# Modal

Полноэкранный алерт поверх размытого экрана — вместо классического диалога-карточки. Под ним весь экран: блюр 64 + тинт `background-overlay` (чёрный 60%); без блюра — `background-page-primary` @ 90%.

| Элемент | Значение |
|---|---|
| Паддинг | 32 по бокам, 56 сверху/снизу |
| Заголовок | `title1`, по центру, `modal/fg-title` |
| Детали (опц.) | слот: рамка, иллюстрация, QR; отступы 32 до и после |
| Подзаголовок | `headLine2`, по центру, `modal/fg-subtitle`; от заголовка 24 |
| Кнопки | прижаты к низу: Tertiary M, зазор 16, Primary L (или HoldToConfirm) во всю ширину |

Блок заголовка центрируется по вертикали; при нехватке высоты всё скроллится. Опц. крестик — `TopBarIcon` в топбаре справа. Тот же макет — для полноэкранных статус-экранов («лимит установлен», ошибки).

### Токены `modal/*`

| Переменная | Семантика | Sportlines Dark | 1x2 |
|---|---|---|---|
| `bg` | `background/overlay` | `#00000099` | `#080B1899` |
| `fg-title` | `foreground/on-dark/primary/default` | `#FFFFFF` | `#F4F1E8` |
| `fg-subtitle` | `foreground/on-dark/secondary/default` | `#FFFFFF99` | `#F4F1E899` |
