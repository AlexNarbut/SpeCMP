# BottomBar

Нижняя навигация Sportlines — карусель табов, выбранный по центру, свайп переключает. Для SpeCMP не нужна (у нас нет таб-бара) — описана для полноты.

- Слот 68 шириной, зазор 4, высота колонки до 128, отступ снизу 8.
- Выбранный: иконка без фона, масштаб 64/68. Невыбранные: круг-стекло (блюр ultraThin, рамка 1 с градиентом `foreground-on-dark-medium-highlight` → `foreground-on-dark-highlight`, паддинг иконки 12), масштаб 54/68.
- Подпись в 3 под иконкой, 64×36, `additional1`, 2 строки, по центру; у выбранного увеличивается до размера `additional0`. Цвет: выбран `foreground-on-dark-primary-default`, не выбран `foreground-on-dark-tertiary`.
- Анимация масштаба 400ms. Вся панель при скролле сжимается со scale 1.25 до 1.0, под ней — блюр ultraThick, плотный снизу.
