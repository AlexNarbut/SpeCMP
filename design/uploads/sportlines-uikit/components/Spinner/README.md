# Spinner

`SpinningProgressBar` — фирменный спиннер. 30, 8 скруглённых палочек (30% ширины × 1/8 высоты). Базовый цвет `foreground-on-dark-light` (20%), бегущий хвост из 4 палочек белого с альфой 0.4 / 0.6 / 0.8 / 1.0. Оборот 640ms, шагами, линейно.

Правило: загружается весь экран или таб — спиннер по центру (без отступов топбара); место одного элемента — скелетон (см. Skeleton).
