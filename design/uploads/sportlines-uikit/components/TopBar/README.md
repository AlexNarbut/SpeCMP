# TopBar

Центрированный топбар. Высота 64, фон прозрачный (`background-page-transparent`), боковой отступ 8. Слоты: навигация (нет / Назад / иконка / свой), заголовок `headLine1` по центру, действия. Кнопки — `TopBarIcon` 56.

**CollapseTopBar:** развёрнутый 112 (заголовок `title1` по центру, отступ сверху 24) → свёрнутый 64 (заголовок `headLine1`). Режимы скролла: exitUntilCollapsed, pinned.

**Блюр:** когда контент уходит под топбар — прогрессивный блюр, плотный сверху (материал thick, тинт `background-page-primary`). Нарастает за первые 80 скролла; у сворачивающегося — включается, когда свёрнут на ≥95%. Подробно — «Эффекты и анимация».
