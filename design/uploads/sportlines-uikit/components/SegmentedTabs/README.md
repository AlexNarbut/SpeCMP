# SegmentedTabs

Segmented-контрол: фона нет, рамка только у выбранного. Зазор 8, паддинг таба 16×12, `headLine1`. Радиус `r-controls-radius`, рамка `w-tags-width`. Выбранный — `border-primary` (pressed `border-tertiary`). Цвета текста и переход 600ms — как у Tabs. Группа центрируется, если влезает, иначе скроллится.
