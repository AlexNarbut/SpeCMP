# SurfaceScale

Шкала поверхностей — главный приём системы: вместо цветных карточек — ступени прозрачности белого на чёрном. `background-surface-ultra-highlight` 5% (disabled, фон ошибки), `background-surface-highlight` 10% (Secondary-кнопка, InputCenter, теги), `background-surface-medium-highlight` 15%, `background-surface-light` 20% (HoldToConfirm, трек Toggle), `background-surface-tertiary` 30%, `background-surface-secondary` 60%, `background-surface-semi` 90%, `background-surface-primary` 100% (Primary-кнопка, выбранный чип, тост). Рамки — та же шкала `border-*`.
