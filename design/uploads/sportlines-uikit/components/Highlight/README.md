# Highlight

Текст в рамке — для крупных значений и шагов. Мин. высота 64, паддинг 12, текст `accident3` (40) по центру. Фон прозрачный, радиус `r-highlight-radius`, рамка `w-highlight-width`. Типы: Default (рамка `border-primary`, текст `foreground-on-dark-primary-default`), Accent (рамка и текст `brand-primary-default`), Info (рамка и текст `info-default`). В колонке плашки сдвинуты на −ширину рамки, чтобы стыки читались одной линией.
