# InfoMessage

Сообщение-подсказка с «хвостиком» снизу слева. Фон `info-message/bg` (белый), радиус `info-message/border-radius`, паддинг 16. Текст `paragraph2` (16, межстрочный 1.2) `info-message/fg`, по левому краю. Хвостик — иконка `speach-arrow` цвета фона, отступ 16 слева.

**SpeechBubble** — вариант с радиусом 20 и хвостом 24×16 (отступ 16 слева): фон `background-surface-primary`, текст `paragraph2` `foreground-on-light-primary-default`.

### Токены `info-message/*`

| Переменная | Семантика | Sportlines Dark | 1x2 |
|---|---|---|---|
| `bg` | `background/surface/primary` | `#FFFFFF` | `#F4F1E8` |
| `fg` | `foreground/on-light/primary/default` | `#000000` | `#080B18` |
| `border-radius` | `card/small-radius` | `0` | `16` |
