# Tabs

Ряд табов без фона и индикатора: выбор читается только цветом текста. Таб: высота 44, паддинг 12, `headLine1`, 1 строка — либо иконка 32. Если табы влезают, группа по центру; если нет — ряд скроллится, выбранный подкручивается к центру (300ms).

Цвета (переход 600ms): выбран — `foreground-on-dark-primary-default` (pressed `-pressed`); не выбран — `foreground-on-dark-secondary-default` (pressed `foreground-on-dark-secondary-pressed`); disabled — `foreground-on-dark-secondary-disabled`. Scale 0.96 + ripple.
