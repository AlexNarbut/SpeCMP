# AppBackground

Фон экрана: `background-page-primary` + радиальное свечение. Цвет свечения — `gradient-brand` / `gradient-success` / `gradient-info` / `gradient-warning` @ 25% (или выключено). Центр по горизонтали, по вертикали Top 0 / Center 0.5 / Bottom 1.0, радиус 0.5 × большей стороны экрана. Смена цвета и позиции — 600ms. Фон привязан к состоянию экрана: загрузка — brand по центру, ошибка — info, контент — выключено или по дизайну экрана.
