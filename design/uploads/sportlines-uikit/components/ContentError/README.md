# ContentError

Экран ошибки загрузки. Отступы экрана (32 по бокам, 16 сверху, 24 снизу), по центру по вертикали. Заголовок `title1` по центру, `modal/fg-title` → 24 → сообщение `headLine2` по центру, `modal/fg-subtitle`, до 4 строк → 32 → Button Primary L («Обновить»). Фон экрана в ошибке — свечение `gradient-info` по центру.
