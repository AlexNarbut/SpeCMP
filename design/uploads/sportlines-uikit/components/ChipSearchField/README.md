# ChipSearchField

Поле поиска, которое встаёт на место ряда чипов. Высота 40, пилюля `r-search-radius`, рамка `w-search-width` цвета `border-highlight`, фон `background-surface-ultra-highlight`. Слева иконка поиска 16 (`foreground-on-dark-secondary-default`), текст `headLine3`, placeholder `foreground-on-dark-tertiary`. Справа крестик 16 в тап-зоне 40×40. Фокус ставится автоматически при появлении.
