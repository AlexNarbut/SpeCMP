# Icons

Монохромные иконки Sportlines, исходник 16×16 из Figma (в коде — Android VectorDrawable, сконвертированы в SVG без изменения геометрии). Заливка #1A1A1A здесь только для видимости на превью. В продукте иконка красится токеном, по умолчанию `foreground-on-dark-primary-default`. Размеры — шкала `icon-s` 16 / `icon-m` 24 / `icon-l` 32 / `icon-xl` 44 / `icon-xxl` 56 / `icon-xxxl` 78. Навигационные стрелки — `pyromid-*` (треугольники), «назад» в топбаре — `arrow-back`.
