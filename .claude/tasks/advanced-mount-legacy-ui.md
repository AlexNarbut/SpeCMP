# Расширенный монтаж в старом приложении (specialistDesktop): что показывалось

Описание для дизайнера. Источник: `specialistDesktop/app/.../mainApp/advancedMount` и `mainApp/alarmDevice`.
Тексты в кавычках взяты из приложения дословно.

---

## 0. Как пользователь попадал на экран

1. Плитка на стартовом экране: **«Расширенный монтаж»**, подзаголовок «Детальная настройка и проверка состояния
   системы».
2. Сразу открывался поиск USB-устройства. Выбора между Bluetooth и USB в рабочей версии не было.
   - Заголовок «Выбери USB устройство».
   - Пока идёт поиск или ничего не найдено: текст «Подключите USB устройство к компьютеру и выберите его для
     дальнейшей работы», ссылка «Инструкции по подключению устройств» и крупный индикатор загрузки.
   - При ошибке: текст ошибки и кнопка «Исправить», которая перезапускает поиск.
   - Строка устройства: иконка устройства, название, идентификатор, разделитель.
3. После подключения открывался экран расширенного монтажа.

## 1. Главный экран расширенного монтажа

### Верхняя панель

- Слева стрелка «Назад». На главном экране она закрывает подключение и возвращает к поиску. Отдельной кнопки
  «Отключить» не было.
- Заголовок «Расширенный монтаж», без подзаголовка.
- Справа иконка удалённого управления с пульсирующей прозрачностью. Она появлялась, только когда сервер сообщал, что
  доступен удалённый монтаж. Нажатие открывает «Удаленная синхронизация».

### Шапка с данными блока

Шапка видна всегда, даже во время загрузки и при ошибках. В ней три строки.

| Строка | Содержимое | Когда показывается |
|---|---|---|
| 1 | **Название блока** (крупно, акцентным цветом), **ID блока** (число), ссылка «Информация о товаре» (подчёркнутая, акцентная) | ссылка только при включённой у пользователя функции поиска товара |
| 2 | «Версия ПО» + версия прошивки (акцентом) | всегда |
| 2, продолжение | «(Версия ПО CAN 12.05)», «CAN код» + код (акцентом), пульсирующая иконка ⚠ с подсказкой | только у блоков с отдельной CAN-прошивкой |
| 3 | «IMEI GSM модема» + IMEI (акцентом) | только если IMEI удалось прочитать из модема |

Текст подсказки у иконки ⚠: «Функционал данного устройства зависит от прошивки CAN. Теперь в первую очередь при
настройке устройства необходимо определиться с CAN кодом автомобиля, обновить прошивку устройства под этот CAN код,
а потом донастраивать систему и проверять ее функции».

**Что в шапке не показывалось:**
- тип подключения (USB / Bluetooth);
- режим работы блока;
- данные блока с сервера (они загружались, но использовались только для переходов).

### Сетка разделов

- 3 колонки.
- Плитка: иконка слева (акцентного цвета), справа заголовок в 1 строку и подзаголовок в 2 строки,
  приглушённый (50 %). Есть подсветка при наведении.
- Плитки либо есть, либо их нет. Неактивных, серых или отключённых плиток не было.

| # | Заголовок | Подзаголовок | Когда показывается |
|---|---|---|---|
| 1 | Проверка прошивок | Обновите прошивки системы до актуальных версий | блок поддерживает обновление прошивки; всегда в режиме «не поддерживается» |
| 2 | Расширенные настройки | Выполните полную настройку системы | блок поддерживает настройки |
| 3 | Бесключевой обход | Обучение бесключевому обходу штатного иммобилайзера | блок поддерживает обучение обходу |
| 4 | Процедура Clone | Вычисление ключа средствами нашего сервера | блок поддерживает Clone |
| 5 | Доп. устройства | Приживляйте и удаляйте устройства Pandora | блок поддерживает дополнительные устройства |
| 6 | Заявки на техпомощь | Просмотрите историю обращений или оформите заявку | блок поддерживает настройки |
| 7 | Чат техподдержки | Напишите о вашей проблеме при монтаже нашим специалистам | всегда |
| 8 | Голосовая прошивка | Обновите голосовую прошивку | блок поддерживает голосовую прошивку |
| 9 | Заявки народных карт | Делитесь своим опытом монтажа | блок поддерживает настройки |
| 10 | Автомобили | Изучение поддерживаемых функций автомобиля | всегда |

**Счётчик непрочитанных в чате.** Приложение раз в минуту проверяло непрочитанные сообщения. Если они были, плитка
чата менялась:
- заголовок «Чат тех. поддержки»;
- подзаголовок «Напишите в чат нашему специалисту о вашей проблеме»;
- на иконке появлялся круглый бейдж с числом в левом верхнем углу (акцентный фон, контрастные цифры).

**Блок с заводскими CAN-настройками.** Плитки 2–5 выглядели как обычные, но нажатие на них открывало диалог (см. п. 2)
вместо перехода в раздел. Визуально такие плитки никак не отличались; это стоит продумать заново.

## 2. Состояния главного экрана

Порядок загрузки после подключения:
1. прочитать возможности блока;
2. проверить блок на сервере;
3. загрузить данные блока с сервера;
4. показать сетку.

IMEI и счётчик чата загружались параллельно.

| Состояние | Что видно на месте сетки |
|---|---|
| Ещё не начали | пусто |
| Загрузка | индикатор по центру |
| Ошибка проверки на сервере | текст ошибки и кнопка «Исправить» (повторяет загрузку) |
| Доступ запрещён | по центру сверху вниз: крупная красная иконка ⚠, заголовок «Доступ ограничен данному устройству», текст причины от сервера, кнопка «Повторить» |
| Блок не поддерживается (не удалось прочитать возможности) | над сеткой красная иконка ⚠ и «Устройство не поддерживается»; в сетке только «Проверка прошивок», «Чат техподдержки», «Автомобили» |
| Готово | сетка разделов |

Отдельного пустого состояния не было.

### Диалог «нужна CAN-прошивка»

- Ширина 75 %, иконка предупреждения.
- Заголовок «Внимание».
- Текст: «Устройство с заводскими CAN настройками. Нужно обновить прошивку под необходимый CAN код автомобиля».
- Кнопки:
  - «Перейти к обновлению» переводит блок в режим загрузчика, и открывается экран прошивки (п. 3);
  - «Отмена».

## 3. Экраны поверх монтажа (состояние связи)

### Связь потеряна

Этот экран открывался поверх любого экрана монтажа, как только связь с блоком переставала быть рабочей.
- Пустой заголовок и стрелка «Назад», которая закрывает подключение.
- По центру иконка «блок отключён» (акцентного цвета).
- Текст: «Отсутствует соединение с устройством. Проверьте USB соединение с устройством».
- Кнопки повтора нет. Когда блок возвращался, экран закрывался сам и пользователь оказывался там, где был.

### Режим загрузчика (обновление прошивки)

Открывался, если блок подключён в загрузчике или пользователь нажал «Перейти к обновлению».
- Заголовок «Обновление прошивки», подзаголовок «Название  ID».
- «Подсистема:» и список подсистем. У каждой: название, имя блока, версия прошивки, CAN-код с пометкой «(Заводской)»,
  версия CAN.
- Выбор типа прошивки.
- Кнопки:

  | Ситуация | Кнопки |
  |---|---|
  | CAN-код известен | «Скачать прошивку для CAN кода …» (только если код не заводской), «Выбор Автомобиля / Архив прошивок» |
  | CAN-кода нет | «Скачать прошивку», «Архив прошивок» |
  | Всегда | «Файловый менеджер»; обводкой «Выйти из режима прошивки» |

- Справа сверху может быть иконка голосовой прошивки.
- Диалог выхода: «Внимание» / «Отключите USB кабель для выхода из режима загрузки».
- Состояния скачивания, прогресса и завершения прошивки.

| Раздел | Заголовок экрана | Что на экране |
|---|---|---|
| Проверка прошивок | «Проверка прошивки» | «Доступные для обновления модули»: у каждого «Актуальная» или «Доступно обновление»; данные CAN; кнопка «Режим обновления»; тот же CAN-диалог и экран «доступ ограничен» |
| Расширенные настройки | «Расширенные настройки» | дерево настроек, редактор значения, диалоги сохранения |
| Бесключевой обход | «Бесключевой обход штатного иммобилайзера» | кнопка «Начать обучение бесключевому обходу»; предупреждения про CAN; просьбы перезагрузить; можно перейти в Clone |
| Процедура Clone | «Процедура Clone» | старт, повтор, завершение; счётчик попыток; статус |
| Доп. устройства | «Доп. устройства» | «Список приживленных устройств»: статусы «приживлено» и «подключено»; приживить, обновить, удалить; ввод адреса |
| Заявки на техпомощь | — | список заявок со статусами; форма создания (имя, телефон, тема); диалоги отмены и закрытия |
| Чат техподдержки | «Чат с тех. поддержкой» | сообщения, поле ввода, отправка файлов (перетаскиванием), сообщения о событиях монтажа |
| Голосовая прошивка | «Голосовая прошивка» | текущая и найденная версия; файловый менеджер; этапы: подготовка, скачивание, установка, готово |
| Заявки народных карт | «Заявки Народных карт» | список заявок и диалог добавления |
| Автомобили | «Выберите автомобиль» / «Поиск автомобиля» | выбор марки, модели и комплектации; «По Can коду»; поддерживаемые функции и их статусы; схемы и карты монтажа |
| Иконка удалённого управления | «Удаленная синхронизация» | пояснение, кнопка старта; этапы: подключение, обработка, завершено |
| Ссылка «Информация о товаре» | «Информация о товаре» | название, ID, серийный номер, дата производства, прошивка и версия, ввод ID упаковки |

## 5. Bluetooth и USB

В старом приложении фактически работал только USB, поэтому Bluetooth-вариантов этих экранов не было. Тексты экрана
потери связи и выхода из загрузчика написаны под USB.

В новом приложении есть оба канала, поэтому:
- нужны тексты потери связи для Bluetooth (например, «блок выключен или далеко»);
- стоит показывать тип подключения в шапке.

## 6. Что нового нужно продумать относительно старой версии

- Тип подключения (USB / Bluetooth) и режим блока в шапке.
- Вид плиток, которые требуют сначала обновить CAN-прошивку: в старой версии они не отличались от обычных.
- Экран потери связи с кнопкой выхода и, при желании, с подсказкой по переподключению для каждого канала.
- Пустое состояние сетки (в старой версии было просто пусто).
- Мобильная раскладка: в старой версии сетка всегда в 3 колонки (десктоп).

## Заметки для разработки

- Когда появлялся счётчик непрочитанных, плитка чата получала тот же идентификатор, что и «Заявки на техпомощь» (15).
  Вероятно, нажатие с бейджем открывало заявки вместо чата. Новая реализация должна это исправить.
- Метка кнопки скачивания CAN-прошивки в строках задана дважды; какая из двух показывается, не проверено.
- «Бизнес заявки» и отдельная плитка удалённого управления описаны в коде, но в сетку не добавлялись.
